# 2B：跨图共享网络的 DASBS，在可精确求解的小图上验证

依据 `docs/20261125/plan.md` 的 2B。代码 `cam/solvers/dasbs.py`（UPSTREAM.md 第 71 条），数学见 `docs/20261125/math_route2.md`。

## 设置

- 小图族 `/usr0/home/shengyuf/yunyi/data/sb_small/`（`cam/scripts/sb/gen_small_graphs.py`）：训练 2000 张、验证 64 张、留出测试 64 张，n = 8–12，随机生成；另有 6 对 1-WL 不可区分的图（`wl/`，共 12 张）。
- 目标 ν ∝ exp(−H/τ)，τ = 1，H = −|x| + 2·（冲突边数）。起点 Bernoulli(0.5)^n。
- 网络：控制器 EncodeProcessDecodeTime2（带时间），修正项 EncodeProcessDecode（不带时间），宽 64、8 层。
- 训练：每次迭代 16 张图 × 16 条链，50 步 τ-leaping 采样（网格在 t = 1 附近加密），每次采样后 4 步梯度；48 epoch × 125 次迭代 = 6000 次迭代；Adam 1e-3，余弦衰减。
- 三组（`launch.sh`）：
  - **sb**：log-linear 参考过程 γ = 1、α = 0.5（不是 memoryless），带修正项，每阶段 200 次控制器 + 100 次修正项。这是完整的 SB。
  - **ml**：memoryless（α = 0），不用修正项。这是没有 SB 的离散 adjoint matching。
  - **nocorr**：参考过程同 sb，但不用修正项。不动点是错的（math_route2.md §6），作对照。
- 评测（`evaluate.sh`，`cam/scripts/sb/dasbs_exact_eval.py`）：对每张图枚举全部 2^n 个状态，逐步精确传播采样器的分布（没有抽样误差），与精确目标比。checkpoint **预先指定为最后一个 epoch**：验证集上的 MIS 大小在这么小的图上饱和（4.5625），不能用来选，所以不做选择。
  - tv：采样分布与 ν 的总变差；src：起点分布与 ν 的总变差；floor：同一采样器换成精确 SB 控制器时的总变差（只有时间离散误差）；half：总变差 ≤ src/2 的图所占比例；Egap：|平均能量 − 目标平均能量| / |目标平均能量|；feas：没有冲突边的概率；corr_err：学到的修正项与精确修正项的 log 平均绝对差（ml 恒为 0，nocorr 是"修正项恒为 1"的误差，即精确修正项本身的大小）。

## 验收标准（plan.md 2B）

1. 修正项恒为 1 且参考过程 memoryless 时，损失与 M2 的 memoryless 特例一致：单元测试 `cam/tests/test_dasbs_solver.py`，**通过**。
2. 留出小图上，τ = 1 时采样分布与精确目标的平均总变差 ≤ 0.20，并且不超过"起点分布到目标的距离"的一半。
3. 采样样本的平均能量与目标平均能量相差 < 10%。

标准 2、3 针对完整的 SB 版本（sb）判定；ml、nocorr 是对照。

三组的总变差都剧烈振荡，不是 SB 特有的问题。最后几个 epoch 变好，多半是学习率余弦衰减到接近 0。所以最终数字主要看振荡停在哪里。另一个混杂：sb 的控制器只得到 4000 次更新（每阶段 200 + 100），ml、nocorr 是 6000 次。

## 第 1 轮修复

- 三组都加参数 EMA（decay 0.999；评测和 checkpoint 用平均后的权重）。依据：DASBS 原文 App. C，"We always use exponential moving average (EMA) to stabilize the training"，原文 decay 0.9999、总共约 3750 步；这里是 6000–9000 步，取 0.999。
- sb 改为每阶段 300 次控制器 + 150 次修正项，72 epoch（20 个阶段），控制器更新次数与 ml、nocorr 相同（6000）。
- checkpoint 仍预先指定为最后一个 epoch。
- 启动：`EMA=0.999 TAG=fix1 bash launch.sh {ml,nocorr} 0`；`EMA=0.999 TAG=fix1 SB_STAGE=300,150 EPOCHS=72 bash launch.sh sb 0`。
