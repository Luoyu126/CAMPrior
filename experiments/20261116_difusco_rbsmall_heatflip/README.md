# 20261116_difusco_rbsmall_heatflip：DIFUSCO 用能量加热的前向（RB-[200-300]）

## 目的

SL 只有一个精确标签，相当于只知道能量的一个最低点；UL 每次在自己的样本上算能量，等于看到了地形。这里检验第一步：DIFUSCO 的前向（标签 → x_t）改成按能量往上坡翻，让训练数据带上地形，看能否缩小和 DiffUCO 的差距。方案见 `docs/20261116/experiment_plan.md` §7，代码见 `cam/UPSTREAM.md` 第 42 条。

## 配置

- 前向：节点 i 在第 s 步的翻转概率是 β_s · σ(λ_s ΔE_i)。ΔE_i 是翻转它带来的 MIS 能量变化，能量与 `cam/envs/mis.py` 相同，β = 1.02。λ_s 从 λ 线性退到 0，在 t = 500 处退完；之后是均匀翻转，终点仍是 Ber(0.5)。
- λ = 0.1（用户 11-16 定，只跑这一组）。
- 验证和测试用重新加噪采样器：网络给出 x₀ 的概率，按它抽一个 x₀，再用同一条加热链加噪到下一步。这样推理时每一步的输入分布和训练一致。
- 其余和 `20261116_difusco_rbsmall_randflip` 完全相同：8 层 × 64，batch 40，AdamW，学习率 2e-4，weight decay 1e-4，cosine 衰减，最多 200 个 epoch，patience 20，推理 50 步 × 20 条链，验证 64 张，单卡，种子 0。

## 选 λ 的依据（11-16 的诊断）

在 40 张训练图上，从标签出发模拟加热链（`cam/scripts/mis/heated_forward_curve.py`）：

| t | 均匀：密度 / 每图冲突边 | λ=0.1 | λ=0.3 | λ=1 |
|---|---|---|---|---|
| 200 | 0.23 / 98 | 0.26 / 138 | 0.32 / 225 | 0.38 / 297 |
| 400 | 0.42 / 365 | 0.51 / 586 | 0.69 / 1082 | 0.81 / 1379 |
| 500 | 0.47 / 454 | 0.53 / 601 | 0.66 / 980 | 0.81 / 1439 |
| 800 | 0.50 / 521 | 0.50 / 518 | 0.50 / 529 | 0.51 / 534 |

- 冲突边：两端都取 1 的边。均匀随机时每张图约 520 条。
- λ ≥ 0.3 时，中间一段会冲过头：密度到 0.6–0.9，冲突边是均匀时的 2–3 倍，标签的点几乎全被锁成 1。这是正反馈造成的：取 1 的点越多，再加点越上坡。λ = 1、3、10 的曲线几乎重合，已经饱和。
- λ = 0.1 比均匀加噪快一些，峰值密度只到 0.53，不会冲过头。

## 结果：训练 × 采样器的 2 × 2 表（11-17）

1000 张 test 图，两个推理种子（0 / 1），CAM 论文协议；脚本 `test.sh`。

| best.pt 来自 | D3PM 后验采样 | 重新加噪采样 |
|---|---|---|
| randflip（均匀前向，按 D3PM 后验选权重，第 119 个 epoch） | 19.314 / 19.290 | 19.608 / 19.628 |
| λ = 0（均匀前向，按重新加噪选权重，第 49 个 epoch） | 19.236 / 19.230 | 19.578 / 19.582 |

- 采样器的影响约 +0.32 到 +0.35，两个 best.pt 上一致；推理种子之间只差约 0.02。
- 两个 best.pt 之间差 0.04–0.07，randflip 的略好，只有一个训练种子，不算显著。λ = 0 的验证最好（19.94）比 randflip（19.67）高，但 test 没有更好，说明 64 张验证图上的差别主要是噪声。
- 参照：DiffUCO bernoulli 19.70 / 19.74，annealing 19.87。换成重新加噪后，DIFUSCO 和 DiffUCO bernoulli 的差距从约 0.4 缩到约 0.1。
- λ = 0 在第 69 个 epoch 早停（patience 20，最好在第 49 个 epoch）。
- 之后 λ = 0.1 要和 λ = 0 的重新加噪格子（19.58）比，不能和 randflip 的 19.31 比。

## 对照（用户 11-16 同意跑）

λ = 0 这组的训练和 randflip 完全相同（均匀前向，走原来的闭式加噪），只把验证和测试的采样器换成重新加噪。于是：
- λ = 0.1 对 λ = 0：只差前向，看能量地形的作用；
- λ = 0 对 randflip：只差采样器，看换采样器本身的影响。
