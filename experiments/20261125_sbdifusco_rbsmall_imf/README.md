# 1D：学出来的配对（离散 IMF，前向与后向两个网络交叉喂入）

依据 `docs/20261125/plan.md` 1D；算法与文献要点 `docs/20261125/math_route1.md` §12（CSBM、DDSBM；"两个方向同时训练"按 §12.4 做成交叉喂入，属于我们的推断）；进度 `docs/20261125/status.md`。

## 做法（`run_imf.sh <gpu 前向> <gpu 后向> <ω> [seed]`）

- 前向网络：SB-DIFUSCO（起点 z → 解），在 (z 来自后向网络，y 来自真标签 π1) 的配对上训练。
- 后向网络：SB-DIFUSCO `--sb_reverse`（解 → 起点），在 (z ~ π0 真起点，y 来自前向网络) 的配对上训练。
- 第 0 次迭代用独立配对；前向网络从独立配对基线（11-19 的 q5_mkamisfix_long_soft_s0，400 epoch，4 卡）继续训练 E0 = 100 epoch，后向从头训练。
- 第 1–3 次迭代：两个网络在每张训练图上各采 J = 16 条链，结果写成对方的配对缓存，各自再训练 E = 50 epoch。
- ω = 0.35（1C 选定）。其余设置同 `experiments/20261125_sbdifusco_rbsmall/launch.sh`。
- 预先指定最终模型为第 3 次迭代的前向网络（best.pt，按验证集前 64 张图选 epoch）。
- 训练预算：前向网络共约 400 + 100 + 3 × 50 = 650 epoch，比 1C 的 400 epoch 多。

运行目录：`runs/experiments/20261125_sbdifusco_rbsmall_imf/20261125_sbdifusco_rbsmall_imf_w0.35_s0/`（`imf.log`、`fwd_it*`、`bwd_it*`、`caches/`、`summary.md`）。第一次启动在 GPU 0、1 上显存不足，目录 `*_oom1` 保留。

## 验收标准与结果

### 标准 1：小图上（表格后验）迭代收敛到 Sinkhorn 配对，TV < 1e-3：通过

`cam/utils/sb_imf.py`、`cam/tests/test_sb_imf.py`（12 项通过）：6 个小实例全部收敛（TV < 1e-3；ω ≤ 1 时 4–19 次投影，ω = 2、3 时 43、70 次），到 SB 的 KL 单调不增；两个反向对照都偏离。

### 标准 2：学到的配对的平均 Hamming 代价随迭代下降，最终与闭式配对相差 < 10%：通过（附注）

4000 张训练图，每图 16 对；闭式 SB 配对（ω = 0.35）在同样的图上平均代价 110.978。

| 迭代 | 前向网络的训练配对（后向生成 z，真 y） | 与闭式之比 | 前向网络自己的配对（真 z → 前向采样的 y） | 与闭式之比 |
|---|---|---|---|---|
| 0（独立配对） | 113.673 | 1.024 | 113.673 | 1.024 |
| 1 | 109.879 | 0.990 | 116.429 | 1.049 |
| 2 | 109.770 | 0.989 | 116.600 | 1.051 |
| 3 | 109.784 | 0.989 | 116.589 | 1.051 |

- 前向网络训练用的配对：代价下降，第 1 次迭代后就稳定在闭式配对之下 1.1%。按标准通过。
- 前向网络自己生成的配对：代价上升到闭式之上 5.1%（仍 < 10%）。原因是前向采样的 y 不一定是标签里的解，它到 z 的距离不受配对约束。这一列不随迭代下降，如实记录。
- 标准本身偏弱（待用户确认，见 status.md）：独立配对在第 0 次迭代就只比闭式高 2.4%。按"缩小了多少差距"看：训练配对从 +2.4% 变成 −1.1%，越过了闭式配对。

### 标准 3：验证锚点上的解质量不低于 1C 最好结果减 0.02：通过

验证锚点（第 64–499 张，436 张），20 个样本取最好，评测种子 0，`--sb_coupling --sb_omega 0.35`：

| 模型 | renoise 50 | 20 | 10 | 5 | posterior 50 | 20 | 10 | 5 |

| 第 0 次迭代 | 19.968 | | 19.631 | | 19.592 | | | |

- 门槛：renoise 50 步 19.977 − 0.02 = 19.957（用 1C 最好的单个种子，最严的口径），19.968 ≥ 19.957；posterior 19.628 − 0.02 = 19.608，19.612 ≥ 19.608。通过。
- 逐图配对差（50 步 renoise）：对 1C ω = 0.35 种子 0 为 −0.009 [−0.044, +0.025]，对配置一致的 ω = 0（两个种子）为 +0.009 [−0.023, +0.041]，都是中性；5 步时对 ω = 0 为 +0.052 [+0.001, +0.102]，与 1C 的 5 步结果一致。
- 起点依赖（成对追踪，评测种子 100）：锚点 renoise 比值 0.969、posterior 0.978；val64 hit 0.167（打乱 0.148）。与 1C 的 ω = 0.35（0.968 / 0.978 / 0.167）几乎相同。

## 判定：通过

三条标准都满足。科学上：学到的配对与闭式 Sinkhorn 配对效果相同（代价、起点依赖、MIS 都打平），没有额外收益；而且前向网络多训练了约 250 epoch。闭式配对在 RB-small 上已经足够，IMF 只是把它近似地学了出来。
