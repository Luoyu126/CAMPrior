# 20261119_difusco_rbsmall_fewstep

目标：固定测试设置（50 步、每图 20 个样本取最大、renoise）下，DIFUSCO 超过 DiffUCO 的 19.883。
起因：同一批检查点在 400 步时已超过 DiffUCO（DIFUSCO 采 200 标签 19.976 对 DiffUCO 19.918 / 19.926），
50 步时差距来自少步采样，而不是标签本身。

## 设置（`launch.sh`，除注明外同 `20261118_difusco_rbsmall_ullabel`：AdamW 2e-4 余弦，200 epoch，每步 40 张图，1 张卡）

| 组 | 做法 | 依据 |
|---|---|---|
| sd | 用 DiffUCO 采 200 标签训练的 DIFUSCO 在训练图上 400 步采 20 个、取最大（平均 19.991）当标签，从零训练 | 把多步采样蒸馏成少步：Kim & Rush 2016（arXiv 1606.07947） |
| sd_ft | 同样标签，从那个检查点续训，5e-5，30 epoch | 同上 |
| tp50_k200 / tp50_kamis | 训练只用 50 个扩散步（余弦噪声），测试 50 步线性调度（50, 49, …, 1），每个测试步都是训练过的转移；DiffUCO 采 200 标签 / KaMIS 标签 | Fast T2T（arXiv 2502.02941，式 4）只在余弦网格的离散时刻训练 |

测试（`test_after_train.sh`）：best.pt，1000 张测试图，后验 / renoise × 测试种子 0 / 1。

- 50 步训练：DiffUCO 标签 +0.06 ~ +0.07（两个种子一致），KaMIS 标签 +0.05 ~ +0.06。离 DiffUCO 还差约 0.05。
- 400 步自采样标签（sd / sd_ft）没有提升：标签质量高（19.99），但 50 步采样能力没变。
