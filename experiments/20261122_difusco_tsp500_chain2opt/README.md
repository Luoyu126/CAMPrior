# 20261122_difusco_tsp500_chain2opt

## 目的

TSP-500 上，采样链内 2-opt 的 scaling：每个去噪步把 x̂₀ 拼成回路、做 d 次 2-opt，再加噪到下一步（`--difusco_sampler renoise_decode --decode_two_opt d`）。问题：

1. 最终解质量随每步 2-opt 次数 d 怎么变？
2. 随采样步数 T 怎么变？总 2-opt 次数相同时，是"步数多、每步少"好，还是"步数少、每步多"好？
3. 换模型（LKH 软/单标签、CAM 软/单标签）是否同样成立？

**文献**：链内"拼回路 + 2-opt + 再加噪"不是新方法：
- IDEQ（Basson & Preux，arXiv 2412.13858，Algorithm 1，`ref/lit_pdfs/ideq_2024.txt:493-505`）：每步做到收敛，用 D3PM 后验；
- PCI（arXiv 2606.09343，Algorithm 1，`ref/lit_pdfs/pci_2026.txt:331-351`）：renoise 形式，用于一致性模型。

两者都没有研究每步 2-opt 预算和步数的 scaling，也没有报告"最后的 2-opt 约 50 次就收敛饱和"。

## 配置

- 模型：`20261121_difusco_tsp500_labels` 训练的 DIFUSCO TSP-500 模型（12 层 AnGNN，宽 256，kNN-50 稀疏图），用 `best.pt`。
- 测试：前 128 个测试实例；16 个样本取最好；最后 2-opt 上限 1000；种子 0。
- 每个实例记录最后做与不做 2-opt 的长度，以及 2-opt 实际次数：链内总次数、最后一次的次数。一次 = 16 个样本的一次批量 2-opt 步。由 `probe.py` 包装 main.py 记录。
- 单 GPU，wandb 关闭。
- 启动：`bash experiments/20261122_difusco_tsp500_chain2opt/test.sh <gpu> <模型 run> <d> [T] [seed]`
- 汇总：`python experiments/20261122_difusco_tsp500_chain2opt/summarize.py [模型 run]`
- 输出：`runs/experiments/20261122_difusco_tsp500_chain2opt/<模型 run>/d<d>_t<T>_seed0.jsonl`

## 结论（暂定）

1. **每步 2-opt 次数有阈值、有饱和**：
   - d ≤ 2 和不做 2-opt 没区别；
   - d = 5–20 迅速变好；
   - d ≥ 20 饱和，因为每步 2-opt 自己约 36 次就收敛。
2. **采样步数是更强的维度**：d20 下 T = 10 → 20 → 50，gap 1.03% → 0.91% → 0.72%，每一档都显著。总 2-opt 次数相近时，"步数多、每步少"更好。所以收益来自 2-opt 与网络交替的次数，而不是 2-opt 总量。
3. **只拼回路（d = 0）也比基线好 0.18 个百分点**：把链中间的 x̂₀ 变成合法回路再加噪，本身就有用。这和训推一致的解释相符：训练时网络见的是"合法回路加噪"。
