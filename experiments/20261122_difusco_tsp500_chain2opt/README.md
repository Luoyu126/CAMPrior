# 20261122_difusco_tsp500_chain2opt

## 目的

TSP-500 上，采样链内 2-opt 的 scaling：每个去噪步把 x̂₀ 拼成回路、做 d 次 2-opt，再加噪到下一步（`--difusco_sampler renoise_decode --decode_two_opt d`）。问题：

1. 最终解质量随每步 2-opt 次数 d 怎么变？
2. 随采样步数 T 怎么变？总 2-opt 次数相同时，是"步数多、每步少"好，还是"步数少、每步多"好？
3. 换模型（LKH 软/单标签、CAM 软/单标签）是否同样成立？

**文献**：链内"拼回路 + 2-opt + 再加噪"不是新方法：
- IDEQ（Basson & Preux，arXiv 2412.13858，Algorithm 1，`ref/lit_pdfs/ideq_2024.txt:493-505`）：每步做到收敛，用 D3PM 后验；
- PCI（arXiv 2606.09343，Algorithm 1，`ref/lit_pdfs/pci_2026.txt:331-351`）：renoise 形式，用于一致性模型。

两者都没有研究每步 2-opt 预算和步数的 scaling，也没有报告"最后的 2-opt 约 50 次就收敛饱和"。

## 配置

- 模型：`20261121_difusco_tsp500_labels` 训练的 DIFUSCO TSP-500 模型（12 层 AnGNN，宽 256，kNN-50 稀疏图），用 `best.pt`。
- 测试：前 128 个测试实例；16 个样本取最好；最后 2-opt 上限 1000；种子 0。
- 每个实例记录最后做与不做 2-opt 的长度，以及 2-opt 实际次数：链内总次数、最后一次的次数。一次 = 16 个样本的一次批量 2-opt 步。由 `probe.py` 包装 main.py 记录。
- 单 GPU，wandb 关闭。
- 启动：`bash experiments/20261122_difusco_tsp500_chain2opt/test.sh <gpu> <模型 run> <d> [T] [seed]`
- 汇总：`python experiments/20261122_difusco_tsp500_chain2opt/summarize.py [模型 run]`
- 输出：`runs/experiments/20261122_difusco_tsp500_chain2opt/<模型 run>/d<d>_t<T>_seed0.jsonl`

### CAM 无监督模型（发布的 CAM TSP-500 checkpoint，10 步，`test_ul.sh`）

CAM 的采样器每步按网络给出的翻转概率翻转边。链内解码（`--ul_chain_decode`）的做法是：每步翻转后拼成回路，做 d 次 2-opt，作为下一步的状态。

| 设置 | 不做最后 2-opt | 做最后 2-opt | 与普通采样差 |
|---|---|---|---|
| 普通采样 | 13.907% | 1.976% | |
| 每步只拼回路（d0） | 14.724% | 1.999% | +0.023 [−0.054, +0.098] |
| d20 | 14.424% | 1.967% | −0.009 [−0.086, +0.064] |

CAM 没有任何收益。另外，即使链里每步都是 2-opt 过的回路，最后一步网络的输出拼回路后 gap 仍有约 14%：干净回路对 CAM 是训练里没见过的输入，它在最后一步把回路改坏了。

## 结论

1. **每步 2-opt 有阈值、有饱和**：
   - d ≤ 2 和不做 2-opt 没有区别，在 T = 100 下也一样（d2：T100 − T50 不显著）；
   - d = 5–20 迅速变好；
   - d ≥ 20 饱和，因为每步 2-opt 约 36 次就自己收敛。
2. **只要每步的 2-opt 够用（d ≳ 10–20），采样步数就是主要的 scaling 维度**：d20 下 T = 10 → 20 → 50 → 100，gap 1.03% → 0.91% → 0.72% → 0.615%，每一档都显著，T = 100 时比基线好 0.80 个百分点。但每步太少时，加步数救不回来：总次数相近时 T100·d5 反而比 T50·d10 差 0.07。所以规律是"每个修正要做到接近局部最优，再增加修正与网络交替的次数"，而不是"2-opt 总量"。
3. **只拼回路（d = 0）也比基线好约 0.18–0.21 个百分点**，所有 DIFUSCO 模型都一样。
4. **对所有监督训练的 DIFUSCO 模型都有效**（d20 比基线好 0.54–0.76），**对 CAM 无监督模型无效**。
   - DIFUSCO 训练时的输入就是"合法回路加噪"，链内把 x̂₀ 修成回路，等于把采样时的输入拉回训练分布；
   - CAM 是在自己翻转链的状态上训练的，修成的回路对它反而是分布外输入。

   这是训推一致性解释的一个对照证据。
5. **标签质量的差距还在**：同样的采样器下，LKH 标签模型比 CAM 标签模型好 0.6–0.7 个百分点。
6. **文献定位**：链内"拼回路 + 2-opt + 加噪"本身出自 IDEQ 和 PCI，不是我们的方法。我们补充的是：
   - 每步预算和步数的 scaling：每步做到收敛并非必要，约 20 次即饱和，步数才是主轴；
   - "最后 2-opt 约 50 次就饱和"这一测量；
   - 训推一致性的解释，以及 DIFUSCO 有效、CAM 无效这组对照。
