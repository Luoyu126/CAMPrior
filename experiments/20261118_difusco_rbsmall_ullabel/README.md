# 20261118_difusco_rbsmall_ullabel：用 DiffUCO 的解当标签训练 DIFUSCO（RB-small）

## 动机

前面的实验排除了标签选法不一致（H2）、训练图数量（H3）、训练比重（`20261118_difusco_rbsmall_graphweight`）。这里检验“标签好不好学”：机器翻译里非自回归模型同样每个位置独立输出、面对多种正确译法，最有效的标准做法是用强教师模型的输出当训练目标（序列级知识蒸馏；Zhou et al. 2020，arXiv 1911.02727），教师的输出对网络来说更“一致”。

- 如果 SL 在 UL 的输出上训练就能接近 UL，说明差距在于 KaMIS 标签对网络不自然、难学。
- 如果仍然学不到，差距在训练目标或训练时看到的状态。

## 标签

`cam/scripts/mis/ul_labels.py`（cam/UPSTREAM.md 第 46 条）：用 DiffUCO 的 RB-small 模型（`20260513_diffuco_rbsmall_annealing` 的 best.pt，测试 19.88）按它自己的测试协议（50 步 × 20 个样本）在 4000 张训练图上采样，每张图取 20 个样本里贪心解码后最大的一个。输出 `data/rb_small_ullabels/train_diffuco.pt`。

- 平均大小 19.907（KaMIS 标签 20.162）；75.1% 的图上不小于 KaMIS 标签；全部是合法独立集。
- 和 KaMIS 标签平均只共享 27.9% 的点；只有 2 张图和 KaMIS 标签完全相同。
- 只有 38 张图的 UL 标签出现在 `data/rb_small_solsets` 的最优解集合里，而 UL 标签在约 3/4 的图上达到最优大小：那份集合（500 条 RLSA 链）漏掉了大部分最优解，最优解个数是很松的下界。

## 设置

除标签外和 KaMIS 标签基线完全一样（8×64，1000 步均匀前向，每步 40 张图，AdamW 2e-4 余弦，200 个 epoch，不早停，验证用 renoise），`--label_set .../train_diffuco.pt --label_choice first`。种子 0（GPU 0,1）、1（GPU 2,3），训练完各测 D3PM 后验 / renoise × 测试种子 0、1。

启动：2026-11-18 12:21（匹兹堡时间）。

结论：
- DiffUCO 的标签明显更好学：交叉熵更低（0.154 对 0.171），模型的解离自己的标签只差 0.16（renoise）/ 0.38（后验），学 KaMIS 标签时是 0.45 / 0.74，差距减半。
- 但标签本身比 KaMIS 小 0.26，好学的收益大部分被抵消：renoise 只 +0.04，后验 +0.12。
- 难图上还是学不像：只有一个已知最优解的图，模型离 DiffUCO 标签还差 0.26（renoise，1.245 对 0.989），所有图平均只差 0.16。
- 所以 KaMIS 标签“难学”是 SL 落后的一部分原因：同样的网络和训练方式，学一个“网络自己能找到”的解，模仿得好得多。下一步可以把两者结合：标签既要好（达到最优大小）又要好学，例如在最优解集合里挑 DiffUCO / 当前模型最容易生成的那个，或者用 DiffUCO 采样中达到最优大小的解。

## 第二轮：标签既好学又够大（11-18 16:44 匹兹堡时间启动）

上一轮的 DiffUCO 标签平均只有 19.91，比 KaMIS 小 0.26，抵消了“好学”的收益。这一轮把标签推到最优大小，尽量保留 DiffUCO 自己的解：

- `diffuco_k200`：每张图 200 个样本里最大的一个（`ul_labels.py --num_k 200`，种子 1）。平均 20.079，91.8% 的图达到 KaMIS 大小。
- `diffuco_fill`：`diffuco_k200`，其余 330 张图换成已知最优解集合（`data/rb_small_solsets`）里离它最近的那个（`polish_labels.py --k 0 --pool`）。平均 20.162，每张图都达到 KaMIS 大小，其中 3670 张是 DiffUCO 自己的解。

补齐时先试过从 DiffUCO 的解出发跑 RLSA（200 条链、3000 步，τ0 = 0.01 / 0.03 / 0.1），330 张图里只有 49 / 86 / 111 张能到 KaMIS 大小。这 330 张图上 DiffUCO 的解离所有已知最优解都很远：到 KaMIS 标签的汉明距离平均 33，到最近已知最优解 31，到 RLSA 补出来的解 27（解本身约 20 个点）。也就是说，DiffUCO 在这些图上落在另一个盆地里，附近没有“同样好学”的最优解，补哪个差别不大。

两种标签各两个种子（GPU 0,1 / 2,3 为 k200，4,5 / 6,7 为 fill），其余设置不变。
