# 20261119_difusco_rbsmall_replay

问题：第一轮 DiffUCO 标签（每张图采 20 个取最大，`20261118_difusco_rbsmall_ullabel` 的 diffuco）比 KaMIS 标签小，
却训练得更好（"好学"）。如果把其中能在附近找到更大解的图换成那个更大的解（只做很小的改动），续训后能否涨点？

## 标签（`build_labels.py`，诊断在 `runs/scratch/stepwise_1119/`）

- 4000 张训练图里，有 996 张的 DiffUCO 标签比 KaMIS 小（平均 19.83 对 20.85）。DiffUCO 标签全部是极大独立集（没有能直接加的点），
  "去 1 加 2"的改动只在 8 / 4000 张图上存在。
- 从标签出发热启动 RLSA（30–1000 步 × 200–1000 条链，五种设置），取大小 ≥ 标签 + 1 且离标签最近（Hamming）的解：
  996 张里 510 张能找到，但近的很少：≤3 个节点 5 张，≤6 个 16 张，≤10 个 53 张。
- 用的是这 53 张（≤10，平均改动 6.9 个节点，大小都 +1）：原标签平均 19.45，改进后 20.45。

## 设置（`launch.sh`）

从第一轮最佳检查点（种子 0 / 1）续训，AdamW 5e-5 余弦衰减，每步 40 张图，1 张卡。

| 组 | 训练集 | 53 张图的标签 | epoch |
|---|---|---|---|
| 改进 × 10 倍 | 4000 张 + 53 张各再重复 9 次（占 11.8%） | 改进后 | 20 |
| 改进 × 3 倍 | 4000 张 + 53 张各再重复 2 次（占 3.9%） | 改进后 | 20 |
| 原标签 × 10 倍（对照） | 同改进 × 10 倍 | 原 DiffUCO 标签 | 20 |
| 只训 53 张，改进 | 只有这 53 张 | 改进后 | 100（约 200 步） |
| 只训 53 张，原标签（对照） | 只有这 53 张 | 原 DiffUCO 标签 | 100 |

测试（`test_after_train.sh`）：最后一个 epoch 的检查点，1000 张测试图，后验 / renoise × 测试种子 0 / 1，50 步 × 20 条链取最好；
另在这 53 张图上 renoise 测试种子 0 测一次。第一轮两个检查点按同样流程重测作参照。

## 结果（11-18 20:35 匹兹堡时间测完）

测试集（2 个训练种子 × 2 个测试种子平均）和 53 张图（renoise，2 个训练种子平均）：

| 组 | 后验 | renoise | 53 张图 |
|---|---|---|---|
| 第一轮（重测参照） | 19.493 | 19.712 | 19.651 |
| 改进 × 10 倍 | 19.490 | 19.707 | 19.698 |
| 改进 × 3 倍 | 19.494 | 19.705 | 19.651 |
| 原标签 × 10 倍（对照） | 19.494 | 19.711 | 19.623 |
| 只训 53 张，改进 | 19.494 | 19.653 | 19.698 |
| 只训 53 张，原标签（对照） | 19.505 | 19.657 | 19.594 |
| 参考：53 张图的原标签 / 改进标签 | | | 19.45 / 20.45 |

逐个数（训练种子 0 / 1）：53 张图上 改进 × 10 倍 19.736 / 19.660，对照 19.679 / 19.566；只训 53 张 改进 19.679 / 19.717，
对照 19.547 / 19.642。只训 53 张时 renoise 测试：改进 19.619、19.587 / 19.711、19.695；对照 19.598、19.631 / 19.696、19.703。

## 结论

1. 测试集上没有任何提升：全量续训的三组和第一轮相差 ≤ 0.01。只训 53 张图会让 renoise 掉 0.06（主要是种子 0 的检查点，掉约 0.1），
   改进组和对照组掉得一样多，是只训少量图的过拟合，和标签无关。
2. 在这 53 张图上，改进标签比原标签高 0.08–0.10（两种续训、两个种子都更高），约相当于多 4–5 张图采到更大的解。方向对，但只测了一个测试种子。
3. 即使只训这 53 张、每张看 100 次，模型在它们上面也只到 19.70，离改进后的标签 20.45 很远：改动 7 个节点左右的更大解，
   模型仍然学不会（采不出来）。
4. 规模上，近距离改进只覆盖 1.3% 的训练图，即使全部学会，训练集均值也只涨约 0.013。要放大"好学标签"的效果，这条路不够。
