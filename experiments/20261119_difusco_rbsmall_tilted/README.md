# 20261119_difusco_rbsmall_tilted

问题：把 DiffUCO 的整个样本分布当标签（每张训练图 200 个样本），每步按 exp(大小 / T) 抽一个（Neural Diving 式倾斜，
arXiv 2012.13349 §6.1.1 式 11），会不会比"每张图只取最大"更好学、50 步测试更高？

## 设置（`launch.sh`）

除标签外与 KaMIS 基线（`20261117_difusco_rbsmall_heatflip` λ = 0）相同：1000 步均匀前向，AdamW 2e-4 余弦，200 epoch，每步 40 张图。
标签：`data/rb_small_ullabels/train_diffuco_all200_sets.pt`（`cam/scripts/mis/ul_samples.py`，DiffUCO 检查点、种子 2）。
T = ∞ 是均匀抽（纯分布蒸馏）；标签期望大小：∞ 19.11，0.5 19.71，0.3 19.92，0.2 20.04。1 个训练种子。

测试（`test_after_train.sh`）：best.pt，1000 张测试图，50 步余弦 × 20 条链取最大，后验 / renoise × 测试种子 0 / 1。

## 结果（后验 种子 0 / 1，renoise 种子 0 / 1）

| T | 后验 | renoise |
|---|---|---|
| ∞ | 19.414 / 19.421 | 19.664 / 19.655 |
| 0.5 | 19.528 / 19.505 | 19.743 / 19.725 |
| 0.3 | 19.494 / 19.473 | 19.699 / 19.724 |
| 0.2 | 19.505 / 19.531 | 19.728 / 19.738 |

参照（同协议 renoise）：DiffUCO 采 20 取最大 19.711，采 200 取最大 19.758；DiffUCO 本身 19.883。

结论：倾斜抽样与"取最大"相当，没有超过；纯分布蒸馏（T = ∞）更差。不再扩大。
