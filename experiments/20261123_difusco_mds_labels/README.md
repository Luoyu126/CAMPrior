# 20261123_difusco_mds_labels

## 目的

在最小支配集（MDS，非 QUBO）上做监督学习和无监督学习的对比：DIFUSCO 用各种标签训练，与 DiffUCO 对比（`20261123_diffuco_mds_ul`）。要检验两个猜想：

1. **标签更好学**：
   - 多个最优解作标签（随机抽一个，或软标签），相对单个最优解应该更好学；
   - 最优解越分散，这个提升应该越大。
2. **采样走训练见过的状态**（训推一致）：
   - renoise 应优于 D3PM 后验；
   - 每步把 x̂₀ 解码成合法解再加噪（`renoise_decode`）是否进一步有用。

**数据**：
- BA-small：BA 图，200–300 个节点，DiffUCO 论文的 MDS 数据。
- RB-small：RB 图，200–300 个节点，用 MIS RB-small 的图。
- 两个数据集各 4000 张训练图、1000 张测试图。

## 标签（`data/mds_labels/`，`cam/scripts/mds/ilp_labels.py`，HiGHS 整数规划，每次求解限时 60 秒）

| | BA-small | RB-small |
|---|---|---|
| 训练集最优大小 | 27.846（全部证明最优） | 9.403 单解 / 9.394 多解（81.8% / 85.8% 证明最优） |
| 每图不同最优解数（最多 8） | 6.99 | 7.50 |
| 两个最优解之间不重合的比例 \|A\B\|/\|A\| | 0.284 | 0.789 |
| 出现过的节点中不在每个最优解里的比例 | 65.5% | 97.0% |
| 测试集最优大小 | 27.839（全部证明最优） | 9.388（81.6% 证明最优） |

- **RB 的最优解高度分散，BA 较集中。**
- **事先写下的预测**：多解标签的收益应该 RB 远大于 BA。
- 参照：DiffUCO 论文 BA-small MDS 一行，DiffUCO 28.30，加条件期望 28.20，Gurobi 27.89。

## 配置

- 训练与 MIS RB-small 的 DIFUSCO 相同（`launch.sh`）：
  - 网络：EncodeProcessDecode 8 层 × 64；
  - 扩散：50 步 cosine；
  - 优化：batch 40，AdamW 2e-4，200 轮。
  - `best.pt` 按验证集选。单解基线（`ilp1_post`）用后验验证，多解（`ilp8*_renoise`）用 renoise 验证。
- 测试（`test.sh`）：1000 张测试图，50 步 linear，20 个样本取最好，种子 0。
- 汇总：`python experiments/20261123_difusco_mds_labels/summarize.py <ba|rb>`。

**BA 小结**：

1. **renoise 在所有模型上都显著优于后验**，gap 从约 0.9% 降到约 0.37%。DIFUSCO 加 renoise 的 27.94 好于 DiffUCO 论文的 28.30 / 28.20。
2. **多解标签在 BA 上没有收益**：用 renoise 时与单解持平，用后验时略差（后者部分可能来自 `best.pt` 的选择方式不同）。
   - BA 的最优解集中，单个解就好学。这与预测一致，但还不是正面证据；要看 RB。
3. **解码后加噪在 BA 上略差**（+0.02 到 +0.06）。
   - 这与 MIS 一致：在好学的 DiffUCO 标签上无收益；只有在难学的 KaMIS 标签上有约 0.2 的收益（`docs/20261116/sl_vs_ul_findings_1121.md` 第 1.2 节）。
   - 它主要补救难学的标签，RB 上要重新看。

### 采样轨迹上的网络输入（训推一致的直接度量，BA 单解种子 0，前 100 张测试图）

`CAM_TRACE_INPUTS`（UPSTREAM.md 第 59 条）记录每一步采样器的输入 x_t，并和"本条链的最终解按训练前向加噪到同一 t"的训练形式输入比较。输出在 `runs/scratch/mds_1123/trace_ba_ilp1_*.jsonl`。

每格是"采样器 / 训练形式"：

| t | 后验：选中数 | 后验：预测对最终解的交叉熵 | renoise：选中数 | renoise：交叉熵 |
|---|---|---|---|---|
| 50 | 123.7 / 123.7 | 0.133 / 0.133 | 123.8 / 123.8 | 0.117 / 0.117 |
| 29 | 88.1 / 88.5 | 0.116 / 0.109 | 88.2 / 88.4 | 0.131 / 0.092 |
| 22 | 67.4 / 68.1 | 0.093 / 0.074 | 67.2 / 67.9 | 0.154 / 0.059 |
| 15 | 48.0 / 49.1 | 0.064 / 0.035 | 47.9 / 48.7 | 0.126 / 0.025 |
| 1 | 28.8 / 29.2 | 0.005 / 0.001 | 28.4 / 28.6 | 0.003 / 0.001 |

- **一阶统计看不出差别**：两种采样器输入的选中节点数、相邻两点都选中的边数，都和训练形式一致，与 MIS 上一样。
- **单个样本的平均大小**：后验 29.01，renoise 28.41。所以 renoise 的优势不只来自 20 个样本里挑最好。
- **轨迹中段 renoise 的预测离最终解更远**（交叉熵更高），说明它一直在改，没有过早定下解。

结论：在 BA 上，"后验的输入偏离训练分布"没有被这些统计直接证实。更符合数据的仍是"renoise 每步重新决定、纠错更多"。训推一致的解释需要更直接的度量，这一点与 MIS 的结论相同。

## 结果：RB-small

参照：测试集最优大小 9.388（81.6% 证明最优，其余为 60 秒内找到的最好解）。

| 模型（标签） | 后验 | renoise | 解码后加噪 |
|---|---|---|---|
| 单个最优解，种子 0 | 9.797 / 4.82% / 60.4% | 9.855 / 5.44% / 60.6% | **9.622 / 2.78% / 76.9%** |
| 单个最优解，种子 1 | 9.803 / 4.87% / 59.8% | 9.823 / 5.10% / 60.9% | **9.650 / 3.11% / 73.9%** |
| 8 个最优解，随机抽一个 | 9.845 / 5.13% / 58.5% | 9.827 / 5.15% / 61.1% | 9.617 / 2.74% / 77.1% |
| 8 个最优解，软标签 | 9.832 / 5.23% / 57.8% | 9.860 / 5.50% / 61.8% | **9.610 / 2.67% / 77.6%** |

配对差（集合大小，负值表示前者更好）：

| 比较 | 种子 0 | 种子 1 |
|---|---|---|
| renoise − 后验 | +0.058 [+0.026, +0.091] | +0.020 [−0.011, +0.050] |
| 解码后加噪 − renoise | −0.233 [−0.267, −0.201] | −0.173 [−0.205, −0.142] |
| 解码后加噪 − 后验 | −0.175 [−0.203, −0.147] | −0.153 [−0.181, −0.125] |
| 种子噪声：种子 1 − 种子 0（后验） | +0.006 [−0.020, +0.033] | |

**RB 单解基线小结**（与 BA 对照）：

1. **单解标签在 RB 上难学**：
   - gap 约 4.8%，BA 上是 0.37–0.9%；
   - 只有约 60% 的图达到最优，BA 上是 75–90%；
   - 与 RB 最优解高度分散（两解之间 79% 节点不同）一致。
2. **renoise 在 RB 上不再优于后验**：种子 0 上显著更差，种子 1 持平。BA 上则是 renoise 全面显著更好。
3. **解码后加噪在 RB 上大幅改善**：比 renoise 好 0.17–0.23，比后验好 0.15–0.18，gap 从约 5% 降到约 3%。在 BA 上它略差。
   - 这与 MIS 上的规律一致：难学的标签（KaMIS）上有收益，好学的标签上没有。
   - 解读：网络没学好标签分布时，每步抽出的 x̂₀ 不是合法的最小支配集。直接加噪后，输入就不是训练见过的"合法解加噪"形式。先解码成合法的极小支配集再加噪，把输入拉回了训练形式。

   这是"采样走训练见过的状态"的一个正面证据，而且只在标签难学时显现。

**RB 多解标签**（与单解两个种子的平均配对比较，负值表示多解更好）：

| 比较 | 后验 | renoise | 解码后加噪 |
|---|---|---|---|
| 8 解随机 − 单解 | +0.045 [+0.018, +0.071] | −0.012 [−0.042, +0.017] | −0.019 [−0.040, +0.002] |
| 8 解软标签 − 单解 | +0.032 [+0.007, +0.057] | +0.021 [−0.010, +0.052] | −0.026 [−0.045, −0.007] |

同一模型内，解码后加噪 − renoise：8 解随机 −0.210 [−0.242, −0.178]，8 解软标签 −0.250 [−0.289, −0.213]。

4. **多个整数规划最优解作标签，在 RB 上也几乎不帮助学习**：
   - 只有解码后加噪下的软标签显著好 0.026（随机抽一个是 −0.019，边缘显著）；其余持平，用后验时更差。
   - 多解标签集的最优大小本身比单解小 0.009，这能解释其中一部分。
   - **这与事先的预测（RB 上多解标签收益大）不符**：同一个求解器的多个最优解，并没有让标签变好学。
   - 与 MIS 一致：MIS 上 KaMIS 多解加软标签也没有接近 DiffUCO 标签（`docs/20261116/sl_vs_ul_findings_1121.md`）。
   - "标签更好学"的关键对照是 DiffUCO 标签，需要先把 DiffUCO 训好（见下节）。
5. **解码后加噪的收益在多解模型上同样大**（−0.21 到 −0.25）。RB 上最好的是"8 解软标签 + 解码后加噪"，9.610，gap 2.67%。

- **第二次运行**：关早停，跑满 1000 轮，但训练失败。
  - BA 测试：第 999 轮 35.97，`best.pt`（第 4 轮左右）30.67；DiffUCO 论文为 28.30。
  - 诊断（`runs/scratch/mds_1123/diag_diffuco.py`）：
    - 第 4 轮的模型把所有节点翻成 0，输出空集；
    - 第 100 轮以后，每个节点每步的翻转概率都约为 0.5，即纯噪声；验证值约 35 只是贪心解码随机集合的结果。
  - **原因是我们实现的 MDS 能量有 bug**（`cam/UPSTREAM.md` 第 65 条）：
    - DiffUCO 在翻转概率（连续值）上计算能量并求导；
    - 我们的能量用阈值数"未覆盖节点"，梯度为 0；
    - 所以损失只看到 `A·Σp`，先把集合清空，再被熵项推到 0.5。
  - 已改为在连续输入上用多线性扩展（0/1 输入不变，所以 DIFUSCO 的全部评测不受影响），测试见 `cam/tests/test_mds.py` 第 6 项。
