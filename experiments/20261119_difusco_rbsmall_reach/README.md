# 20261119_difusco_rbsmall_reach

目标：从"更差的标签（DiffUCO 解）反而训出更好的 DIFUSCO"出发，量化标签的"好学程度"，再一步步构造更好学的标签，
在固定测试设置（50 步、每图 20 个样本取最大、renoise）下超过 DiffUCO 的 19.883。全部是监督学习。
训练设置同 `20261119_difusco_rbsmall_fewstep` 的 tp50（50 个扩散步、余弦噪声、50 步线性测试调度，200 epoch，AdamW 2e-4）。
当前最好的基线：tp50 + DiffUCO 采 200 取最大（k200），三个种子 19.815–19.836。

## 1. 量化"好学程度"（`learnability_analysis.py`，前 1000 张训练图）

"差距" = 标签大小 − 训练后的模型在该训练图上 50 步、20 个样本取最大的结果。

| 候选度量 | 与差距的秩相关（k200 标签 / KaMIS 标签） |
|---|---|
| 单步去噪损失 D（没见过该标签的参考模型，`cam/scripts/mis/label_learnability.py`） | 0.18 / 0.04 |
| 标签大小在 DiffUCO 200 个样本中的"常见程度"（≥ 该大小的比例） | **0.70 / 0.68** |

按常见程度分组的差距（k200 / KaMIS）：< 5% 0.75 / 0.86，5–20% 0.25 / 0.45，20–50% 0.02 / 0.10，≥ 50% −0.01 / 0.00。
少步采样器（DiffUCO）能常采到的大小，模型就能学会；单步损失看不出这一点（与 Di4C 的论点一致：每一步逐节点独立，
误差在多步复合时出现）。

## 2. 第一轮：学生自己可达的标签（`cam/scripts/mis/reach_labels.py`）

k200 学生（种子 0）在 4000 张训练图上 50 步采 200 个：最大解平均 20.064（它的标签 20.079），93% 的图大小相同，
平均 26.6% 的样本达到最大；每图约 52 个互不相同的最大解。

| 标签 | 训练 | renoise 测试（训练种子 0：测试种子 0 / 1；种子 1：0 / 1） |
|---|---|---|
| r1_self：最大解的中心（与其他最大解最一致的那个） | 从零 | 19.775 / 19.791；19.767 / 19.778 |
| r1_union：r1_self 与 k200 取更大 | 从零 | 19.748 / 19.740；19.775 / 19.762 |
| r1_toprand：全部最大解随机抽 | 从零 | 19.813 / 19.834；19.833 / 19.802 |
| r1_self_ft / r1_union_ft | 从 k200 学生续训 30 epoch | 19.77–19.81 |

都没有超过基线。学生自己可达的解并不比 DiffUCO 的解好学；续训一律略降（之前的续训实验也如此）。

## 3. 机制：好学程度 = 单样本质量；还需要多样性

一步探针（`cam/scripts/mis/label_probe.py`：前 3000 张图上训练"从图一步预测标签"，后 1000 张图上的交叉熵，两个种子平均）
与模型在测试集上的单样本统计（50 步、20 个样本，训练种子 0）：

| 标签 | 探针交叉熵 ↓ | 单样本均值 | 组内标准差 | 取 20 最大 |
|---|---|---|---|---|
| r1_self | 0.242 | 18.93 | 0.61 | 19.78 |
| r1_union | 0.245 | 18.91 | 0.61 | 19.75 |
| k200 | 0.261 | 18.85 | 0.70 | 19.82 |
| fill（k200 补齐到 KaMIS 大小） | 0.264 | 18.90 | 0.67 | 19.82 |
| KaMIS | 0.273 | 18.61 | 0.78 | 19.74 |
| （参照）DiffUCO 本身 | — | 19.08 | 0.54 | 19.88 |

更好预测的标签让单样本更好（KaMIS 最差、学生自己的标签最好）；但每图只有一个很"平滑"的标签时，模型过于集中，
组内标准差下降，取 20 最大反而变差（"训练中选最可能的最大解" tp50_near：18.95 / 0.58 / 19.76 同理）。

## 4. 第二轮：探针挑选的多个 DiffUCO 标签（`cam/scripts/mis/probe_select.py`，11-19 16:40 启动）

每张图在 DiffUCO 200 个样本的最大解中，按交叉拟合探针（在另一半图的 k200 标签上训练）的对数似然挑出最好预测的 M 个，
训练时每步随机选一个：M = 1、4、16；对照：最难预测的 4 个（dselbot4）、全部最大解（dtop）。各 2 个种子。
同一张图的最大解之间，探针对数似然平均相差 12.9。

结果（renoise；训练种子 0：测试种子 0 / 1；种子 1：0 / 1）与每图标签集两两平均 Hamming 距离（前 500 张图）：

| 标签集 | 每图个数 | Hamming | renoise | 平均 |
|---|---|---|---|---|
| dselM1 最好预测的 1 个 | 1 | 0 | 19.739 / 19.750；19.755 / 19.766 | 19.753 |
| dselM4 最好预测的 4 个 | 3.7 | 14.3 | 19.769 / 19.764；19.761 / 19.765 | 19.765 |
| dselM16 最好预测的 16 个 | 12.7 | 17.8 | 19.800 / 19.803；19.821 / 19.803 | 19.807 |
| **dselbot4 最难预测的 4 个** | 3.7 | 22.4 | 19.860 / 19.846；19.835 / 19.827 | **19.842** |
| **dtop 全部最大解** | 57.0 | 21.5 | 19.864 / 19.845；19.828 / 19.832 | **19.842** |
| （基线）k200 单个标签 | 1 | 0 | 三个种子 19.815–19.836 | 19.828 |

与预想相反：在 DiffUCO 风格的解里挑"最好预测的"让标签集变得相似（Hamming 14.3），模型更集中，取 20 最大更差；
标签集越多样越好。好学程度因此有两个维度：单个标签的风格（DiffUCO 风格好学，KaMIS 不好学），以及每图标签集的多样性。

## 5. 第三轮：更多样的 DiffUCO 标签（`cam/scripts/mis/diverse_labels.py`）

DiffUCO 每图采 1000 个（`train_diffuco_all1000.pt`，种子 7），取全部最大解（d1000all），或按 Hamming 最远点采样挑 4 / 16 个
（d1000fps4 / d1000fps16）；200 个样本的最远点 4 个（d200fps4，Hamming 27.3）；d1000all 训练 400 epoch（d1000all_long）。

结果（renoise；训练种子 0：测试种子 0 / 1；种子 1：0 / 1；Hamming 同上，前 500 张图）：

| 标签集 | 每图个数 | Hamming | renoise | 平均 |
|---|---|---|---|---|
| d1000all 1000 个样本的全部最大解 | 243.2 | 21.2 | 19.855 / 19.844；19.838 / 19.816 | 19.838 |
| d1000fps16 | 14.1 | 24.8 | 19.831 / 19.866；19.819 / 19.799 | 19.829 |
| d1000fps4 | 3.8 | 28.3 | 19.859 / 19.839；19.835 / 19.841 | 19.844 |
| d200fps4 | 3.7 | 27.3 | 19.840 / 19.843；19.837 / 19.833 | 19.838 |
| （第二轮）dtop / dselbot4 | 57.0 / 3.7 | 21.5 / 22.4 | | 19.842 / 19.842 |

多样性已经饱和：Hamming 从 21 到 28、每图从 4 个到 243 个标签，四组都在 19.83–19.84（种子间波动约 ±0.02），
没有再超过第二轮。只靠"在 DiffUCO 最大解里挑更多样的"这一条路走不到 19.883。

注意：每图 243 个标签、200 epoch 时，每个标签只被看到不到 1 次，随机选一个当目标的方差很大，这是下一轮的出发点。
