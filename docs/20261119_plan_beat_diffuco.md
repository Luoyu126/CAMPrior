# 让 DIFUSCO（监督）在固定 50 步设置下超过 DiffUCO（无监督）：发现、文献与计划（RB-small MIS，2026-11-19）

**最终目标**：固定测试设置——50 步、每图 20 个样本取最大（best-of-20）、贪心解码、renoise 采样器——下，DIFUSCO 超过
DiffUCO 的 **19.883**（1000 张 RB-small 测试图）。更多推理步数只用来解释两种训练得到的模型各有什么能力，不算达成目标。
两边网络相同（EncodeProcessDecode，64 维 8 层），每步计算量相同。

## 1. 发现

### 1.1 差距来自"少步采样"，不来自标签质量

| 模型（训练标签） | 50 步 | 100 步 | 200 步 | 400 步 |
|---|---|---|---|---|
| DiffUCO | **19.883** | 19.904 | 19.908 | 19.918 / 19.926 |
| DIFUSCO（KaMIS） | 19.679 | | 19.902 / 19.888 | 19.959 / 19.960 |
| DIFUSCO（DiffUCO 采 20 取最大） | 19.711 | 19.798 | 19.870 | 19.935 / 19.922 |
| DIFUSCO（DiffUCO 采 200 取最大） | 19.758 | | 19.919 | 19.976 |

- 同一个 DIFUSCO 检查点，400 步时已超过 DiffUCO；DiffUCO 从 50 到 400 步只涨 0.04，DIFUSCO 涨 0.2–0.3。
- 单样本平均：50 步 DIFUSCO 比 DiffUCO 低 0.7（18.36 对 19.08），400 步只低 0.09。
- "DiffUCO 标签更好学"在 50 步成立、400 步消失：训练图上，标签在 DiffUCO 自己分布里越常见，50 步越容易采到
  （标签在 DiffUCO 200 个样本里排前 5% 的图，差距 0.78；排在一半以内的图，差距约 0）。"好学"= 少步能采到。

### 1.2 解释：逐节点独立的去噪器，少步时有原理上的误差

- Di4C（Hayakawa et al., ICML 2025，arXiv 2410.08709，§1、§2.2、定理 1）：每步把各维当独立分布的"乘积模型"去噪器，
  N 步采样的总变差误差是 O(1/N)，并且在一个二维例子里这个阶不能再改进；少步要做好，必须建模维度间的相关性。
  他们的做法是"混合模型"（给乘积模型加一个随机隐变量 λ，对 λ 取期望，§3.2）+ 从多步教师蒸馏（§3.3）。
- DIFUSCO 每步就是乘积模型（每个节点独立预测 x0），训练时每个时刻单独学边缘分布。DiffUCO 对整条 50 步链做联合优化
  （能量 + 熵，按轨迹），相当于直接学"50 步复合后"的分布。这与 §1.1 的现象一致。

### 1.3 在 50 步设置下已试过的做法

| 做法 | 50 步 renoise 取最大 | 结论 |
|---|---|---|
| 1000 步训练，DiffUCO 采 200 标签（基线） | 19.758 | |
| **50 个扩散步训练（余弦噪声），采 200 标签，两个种子** | **19.815 / 19.833，19.827 / 19.824** | **+0.07，唯一有效** |
| 50 个扩散步训练，KaMIS 标签 | 19.738 / 19.731（KaMIS 基线 19.679） | +0.06 |
| 400 步自采样标签（训练图上 19.99），从零 / 续训 | 19.72–19.74 / 19.69–19.74 | 无提升 |
| 按大小加权抽 DiffUCO 全部样本（T = ∞, 0.5, 0.3, 0.2） | 19.66, 19.73, 19.71, 19.73 | 无提升 |
| on-policy：模型自己走 j 步后的状态上回归标签（DAgger 式） | 18.95–19.56（对照续训 19.72） | 明显变差 |
| 测试时加能量梯度引导（λ 0.25–4） | 19.755–19.777 | 无提升 |
| 近距离局部改进 replay、多最优解选择 | 测试集不变 | 无提升 |

实验目录：`experiments/20261119_difusco_rbsmall_{fewstep,tilted,replay}`；on-policy 与引导的脚本在 `runs/scratch/`。

## 2. 文献（均已下载到 `ref/lit_pdfs/` 并核对原文）

- Di4C（arXiv 2410.08709）：见 §1.2。
- Fast T2T（Li et al., NeurIPS 2024，arXiv 2502.02941，式 4、表 4）：在余弦网格的离散时刻上训练，要求不同时刻、不同噪声
  轨迹都映到最优解，可 1–5 步生成。RB-[200-300] 贪心：DIFUSCO 100 步 18.52，Fast T2T 1 步 18.59、5 步 18.74，
  加梯度搜索 19.37 / 19.49。协议和数值与我们不同（我们的 DIFUSCO 取 20 最大为 19.76），只说明方向。
- T2T（Li et al., NeurIPS 2023，§3.3）：测试时目标梯度引导的"加噪—去噪"。
- DIFUSCO（arXiv 2302.08224，§4.2）：增加步数通常比多采样更有效；训练 T = 1000。
- DiffUCO（arXiv 2406.01661，§6.2）：推理步数多于训练步数还能提升。
- CADO（Song et al., TMLR 2026，arXiv 2602.08210，摘要、§6.3–6.5、表 3–5）：认为监督训练（交叉熵）和解的代价不一致；
  从监督训练的 DIFUSCO 出发，把去噪过程当作 MDP，用解码后解的代价做强化学习微调；"标签中心奖励"把标签解的代价当作
  每个实例的基线（式：R = −(c(f(x0)) − b(g))），不再当模仿目标。MIS-ER 上 DIFUSCO 差距 18.53% → 2.78%；
  对照"多训 50% epoch 的监督微调"（DIFUSCO+SFT）几乎不涨，从零做 RL 也明显更差（§6.4）——和我们"监督训练已饱和"一致。
  他们的 MIS 数据是 SATLIB 和 ER，没有 RB。
- PT-Denoise（Mielke et al. 2026，arXiv 2609.37323，摘要、§5）：测试时让多条去噪链做并行回火、交换温度，不重新训练；
  在 DiffUCO 上把 RB-small 的相对差距从 1.79% 降到 0.47%。属于改变推理过程，DiffUCO 同样受益。
- DISCO（arXiv 2406.19705）：连续（高斯）扩散 + 解析形式的去噪来减少步数，不涉及离散逐节点独立的问题，参考价值低。
- StruDiCO（NeurIPS 2025）、NExCO（ICLR 2026）：逐步选变量 / 掩码扩散，按顺序确定变量，绕开了逐节点独立；
  OpenReview 的论文 PDF 被浏览器验证拦截，未能下载核对，只克隆了官方代码到 `ref/StruDiCO`、`ref/NExCO`（MIS 测试用 1 步推理），
  论文内容暂不引用。
- 渐进蒸馏（Salimans & Ho, ICLR 2022，arXiv 2202.00512）：把 N 步教师蒸馏成 N/2 步学生，反复进行（连续扩散）。
- Sequence-level KD（arXiv 1606.07947）、ReST（arXiv 2308.08998 §3）、Neural Diving（arXiv 2012.13349 §6.1.1）、
  ASBS（附录 C，replay buffer）：我们按这些做的自蒸馏、阈值过滤、加权、replay 在 50 步下都没有提升（§1.3）。

## 3. 计划（按信心从高到低）

### 计划 1（已完成，饱和）：50 步对齐训练

第二批（`experiments/20261119_difusco_rbsmall_fewstep` README）：三个训练种子 19.815–19.836；400 epoch 19.833 / 19.838；
100 个扩散步 19.809 / 19.835；补齐标签 19.822 / 19.835；加权抽 19.81；"选最可能的最大解" 19.75；KaMIS 第二个种子 19.78 / 19.79。
稳定 +0.07，但停在 19.83，离目标还差约 0.05。它是后面计划的起点（初始化 / 基线），本身不再扩展。

### 计划 2（信心中，没有组合优化上的先例）：Di4C 式蒸馏——用 400 步的 DIFUSCO 当教师，训练能表达节点相关性的 50 步学生

教师（采 200 标签检查点）400 步已有 19.976，高于 DiffUCO。按 Di4C 的结论，乘积模型学生学不到这种分布，必须加相关性。
- 学生：50 步网络，节点特征里加一个每张图共享的随机隐变量 λ（例如 8 维高斯，Di4C §3.2 的混合模型；采样时每条链抽一个）。
  从计划 1 最好的 50 步检查点初始化。
- 损失：Di4C §3.3 的蒸馏 + 一致性损失——学生一步 t→s 要匹配教师从 x_t 起走 8 小步到 s 的分布；在 t 接近 0 处匹配教师的 x0。
- 成功标准：50 步 ≥ 19.88，并且单样本均值明显上升（这才说明是学到了相关性，而不是多样性带来的）。
- 代价：要改模型输入并写蒸馏训练循环，约 1 天；训练时教师滚动 8 步，每步约 9 倍前向。
- 风险：Di4C 的实验是图像和文本，没有组合优化；GNN 能否用好全局 λ 不确定；对 λ 的期望用有限样本估计，梯度方差大。

### 计划 3（信心中高，有直接文献）：CADO 式——从 50 步监督检查点出发，按解的大小做强化学习微调

DiffUCO 的优势是对整条 50 步链做联合优化；CADO 在 DIFUSCO 上正是这样做的（§2），并且报告"继续监督训练不涨、RL 微调大涨"，
与我们 50 步对齐训练饱和在 19.83 的现象一致。
- 做法：从 tp50_k200 检查点（19.83）出发，50 步 renoise 采样，按贪心解码后的大小减去标签大小作奖励（标签中心奖励），
  REINFORCE 微调；保留部分监督损失防止漂移。
- 成功标准：50 步 ≥ 19.90，两个种子；同时报告单样本均值与组内标准差。
- 代价：写一个 RL 微调循环（每步要采 50 步链并解码），约半天；训练约几小时。
- 风险：这用到了奖励（解的大小），不再是纯监督——但标签仍是必需的（作基线 / 初始化），CADO 把它归为"SL 求解器的微调"；
  需要你确认这在研究问题里算不算"DIFUSCO 的训练"。RB 上没有直接先例；REINFORCE 方差大，可能需要多条链做组内基线。

### 计划 4（信心低）：测试时搜索（T2T / Fast T2T 的梯度搜索）

我们的能量梯度引导已经是负结果；而且搜索改变了推理设置（额外步数），DiffUCO 也能接同样的搜索。只作为最终系统的组件。

### 不建议继续
自采样标签蒸馏、按大小加权、on-policy 回归固定标签、近距离 replay、多最优解选择：在 50 步设置下均已有负面结果（§1.3）。
