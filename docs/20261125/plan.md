## 0. 要回答的问题

**薛定谔桥（下文简称 SB）学到的"随机起点 → 解"的就近对应关系，能不能让模型在 RB-small 最大独立集上采样得更好？**

| 路线 | 两端各有什么 | 性质 | 方法依据 |
|---|---|---|---|
| 路线 1 | 起点 Bernoulli(0.5) 有样本；终点有样本（KaMIS 多解，或解加扰动） | 有监督 | 离散 SB 的静态解（Sinkhorn）加 bridge matching；对照 DSBM / DDSBM 的迭代做法 |

## 2. 两条路线的数学表述

记号：x ∈ {0,1}^N；s^m 是一张图的第 m 个标签解；π0 = Bernoulli(0.5)^N；参考过程 Q 是每个比特独立翻转，从起点到终点的总翻转概率为 p；ω = log((1−p)/p)。

### 2.1 路线 1：两端都有样本

**静态解。** SB 的配对是

```
π*(x0, x1) = f(x0) · Q(x1 | x0) · g(x1)，   Q(x1 | x0) = p^d (1−p)^(N−d)，d = Hamming(x0, x1)
```

终点是有限个标签时，把只依赖 x0 或只依赖标签的因子吸收进 f、g，得到

```
π*(x1 = s^m | x0)  ∝  g_m · exp( 2ω · |x0 ∧ s^m| )
```

也就是**挑和 x0 的取 1 节点重合最多的标签**，ω 越大挑得越坚决。g 由"各标签被选中的总频率等于 π1"决定，用 Sinkhorn 迭代求，对 x0 的期望用蒙特卡洛。

**动态解。** SB 是参考过程的 h 变换，所以给定中间状态 x_t：

```
P*(x1 = s^m | x_t)  ∝  g_m · Q_{t→1}(s^m | x_t)
```

网络的回归目标是 E[x1 | x_t] = Σ_m w_m s^m。这和现有软目标的形式相同，只多了权重 g_m，并且参考过程在终点不完全混合。

**训练样本怎么来**（都有闭式，不需要模拟轨迹）：

1. x0 ~ Bernoulli(0.5)；
2. 按 π*(· | x0) 抽一个标签；
3. 按参考过程的桥 Q(x_t | x0, x1) 抽 x_t，每个比特独立。

**采样器。** 两种都要实现并比较：

- 马尔可夫后验采样：x_s ~ Σ_{x1} P̂(x1 | x_t) · Q(x_s | x_t, x1)。这是 SB 过程本身。
- 桥式重加噪：x̂1 ~ 网络预测，x_s ~ Q(x_s | x0, x̂1)，x0 是这条链最开始的起点。p = 0.5 时它退化成现有的 renoise 采样器。

**两个极限。**

- ω → 0（p → 0.5）：g_m = π1(m)，配对独立，整个方法**退化成现有的"多解 + 软目标"DIFUSCO**。这是实现正确性的回归测试。
- ω 大：接近确定性的最近匹配。

**量级。** 随机 x0 与一个 20 个点的解重合约 10 ± 2.2 个点，所以有意义的范围大致是 ω ∈ [0.1, 0.5]，即 p ∈ [0.475, 0.38]。

**已做的数值核对**（11-25，`runs/scratch/sb_plan_1125/check_static_sb.py`，N = 8，精确枚举）：配对的闭式、P*(x1 | x_t) 的公式、采样器终点等于 π1、SB 的 KL 低于独立配对，四项全部通过。这只是写方案前的抽查，阶段 M1 要做完整的验证。

**关于"两个网络同时训练"。** 标签集有限且已知时，训练图上的配对可以直接算出来，不需要迭代。标签是在线生成的（例如每步随机扰动）或集合很大时，没有闭式，这时用 DSBM / DDSBM 的迭代：前向、后向两个网络在同一批 (x0, x_t, x1) 上同时训练。阶段 1D 做这个，并用闭式解检验迭代是否收敛到同一个配对。

### 2.2 路线 2：终点只有能量

目标分布 ν(x) ∝ exp(−H(x)/τ)，H(x) = −Σ x_i + λ Σ_{(i,j)∈E} x_i x_j，λ > 1。

DASBS 已经给出离散版的全部结构（下面式号是该论文的）：

- 最优翻转速率 = 参考速率 × φ_t(翻转后) / φ_t(当前)（定理 3.1）。
- **控制器的目标**（式 19–20）：φ 的比值等于终点比值 φ_1(x1 翻转第 i 位) / φ_1(x1) 的条件期望。终点比值 = 能量的翻转差给出的倍率 ÷ 修正项的倍率。
- **修正项的目标**（denoising matching）：参考转移核比值的条件期望。
- 两者交替训练，等价于 IPF，收敛到 SB（定理 5.2）。
- 起点是均匀分布时，修正项初始化为 1（命题 B.12）。
- 参考过程不完全混合（非 memoryless）时修正项才非平凡；该论文的消融显示非 memoryless 更好。

**要匹配的是比值本身，不是比值的对数。** "比值条件期望的对数"不等于"对数比值的条件期望"。本机推导记录 §10–§11 有精确反例。

**DASBS 没有覆盖、需要自己推导并验证的部分：**

1. 二值状态、带温度 τ、MIS 能量下的具体形式，包括能量翻转差的显式式子。
2. 跨图共享网络：控制器和修正项都以图为条件，样本缓冲区按图组织。要证明恒等式对每张图分别成立，所以对图取期望后损失的最优解不变。
3. 训练中温度退火：τ 变化时修正项对应的目标也变，交替更新是否仍然自洽，要不要在每个温度重新拟合。
4. 50 步的离散时间采样：恒等式是连续时间的，τ-leaping（命题 B.7）带来多大误差。
5. 与路线 1 的对应：取 ν = 标签集上的 π1 时，路线 2 的精确解必须等于路线 1 的 Sinkhorn 解。

每个阶段的结果有三种：**通过**、**失败**（实现或数学没达到验收标准）、**阴性**（做对了，但科学结论是"没有提升"）。阴性不算失败，照常写报告、进入下一阶段。

- 50 步 × 20 个样本的平均最大独立集大小（主指标）；单样本平均；
- 少步数：5、10、20 步 × 20 个样本；
- 两种采样器各自的结果；
- **起点决定解的程度**：同一个 x0 跑两次采样得到的两个解的 Hamming 距离，对比不同 x0 得到的两个解的距离。比值越小，说明模型越是学到了"起点 → 解"的对应。独立配对的基线上这个比值应接近 1。
- 在 64 张验证图上另外生成 KaMIS 多解（用 `cam/scripts/mis/kamis_multi.py`），统计样本落在"与 x0 重合最多的标签"附近的比例。

**验收标准**

- 流程验收：所有 run 正常结束，指标齐全，README 写完。
- 科学结论按验证锚点上的逐图配对差（SB 减基线，95% 置信区间）分三档：
  - **阳性**：50 步时 ≥ +0.03 且区间不含 0；或 10 步时 ≥ +0.05 且区间不含 0。
  - **中性**：差距在 ±0.03 以内。
  - **阴性**：≤ −0.03。
- 阴性时允许做 1 轮诊断（最多 20 GPU 小时），例如检查是采样器的问题还是训练目标的问题。之后仍然阴性，1D 跳过，1E 只跑最小集合（见 1E）。

### 1D：学出来的配对

**前置**：下载并读 CSBM（arXiv 2502.01416），连同 DDSBM 的算法部分，把要点写进 `math_route1.md` 的附录。

**做什么**

- 实现 DSBM / DDSBM 式的迭代：前向（起点 → 解）和后向（解 → 起点）两个网络，在同一批样本上同时训练；配对由当前网络生成。初始配对用独立配对。
- 用 1C 中最好的 ω。

**验收标准**

1. 小图上（表格后验）迭代收敛到 Sinkhorn 配对，总变差距离 < 1e-3。
2. 训练图上，学到的配对的平均 Hamming 代价随迭代下降，最终与闭式配对的代价相差 < 10%。
3. 验证锚点上的解质量不低于 1C 最好结果减 0.02。达不到记为阴性，不算失败。

### 1E：标签变体

**前置**：先做一个不训练的小分析，确定扰动的具体形式，写进本阶段 README。候选：

- 等大小交换：去掉一个已选点，加入一个因此变得可选的点。得到的仍是同样大的独立集。
- 删点：去掉 1–2 个已选点。得到小一些的可行解。
- 随机翻转若干位后贪心修复成极大独立集。

对每种扰动统计：解的大小分布、与原解的 Hamming 距离、不同解的个数。

**做什么**：用 1C 最好的 ω 训练下面各组，每组 1 个种子，400 epoch。

| 组 | 终点分布 π1 |
|---|---|
| 单解 + 扰动 | 原始单个 KaMIS 标签及其扰动，等权 |
| 单解 + 扰动，加权 | 同上，权重 ∝ exp(解的大小 / T)，T 取 2 个值 |
| 多解 + 扰动 | KaMIS 多解及其扰动，等权 |
| 多解 + 扰动，加权 | 同上，加权 |
| 多解（更多） | `k128_loaderorder.pt`，每图 66.9 个 |

每组同时跑一个独立配对（p = 0.5）的对照，这样才能把"标签变了"和"配对变了"分开。1C 为阴性时，只跑"多解 + 扰动"和"单解 + 扰动"两组及其对照。

**验收标准**：所有组指标齐全；报告里明确回答三个问题：扰动有没有用、加权有没有用、SB 的收益是否依赖标签形式。

### 1F：加固

**做什么**：1C–1E 中验证锚点上最好的配置，3 个训练种子，800 epoch；同样预算的独立配对基线 2 个种子。只在这一步之后看测试集，并与 DiffUCO（19.880）、CAM（19.907）、DiffUCO 多解软目标 800 epoch（19.890）并列。

**验收标准**：最终表格含均值、种子间标准差、逐图配对差的置信区间。

### 2A：迁移单图 DASBS

**做什么**：把 `../sb_worktrees/DASBS/mis_sb/` 中与网络结构无关的部分（精确枚举、参考过程、损失、Sinkhorn 真值）迁到本仓库，按 M2 的结论修正。

**验收标准**：迁移后的测试全部通过；在 path6、cycle8 两张小图上复现 11-15 的结果（15 个训练阶段后，采样分布与目标的总变差距离分别约 0.09 和 0.14，允许 ±0.05）。

### 2B：跨图共享网络，小图上验证

**做什么**

- 在 `cam/solvers/` 里实现跨图共享的 DASBS：控制器是带时间输入的 GNN，修正项是不带时间的 GNN；起点 Bernoulli(0.5)；均匀翻转的参考过程；控制器和修正项交替训练。记入 `cam/UPSTREAM.md`。
- 在一族可以精确求 SB 的小图上（节点数 8–12，随机生成，训练图和留出图分开）训练和评测。

**验收标准**

1. 修正项恒为 1 且参考过程 memoryless 时，损失与 M2 中的 memoryless 特例一致（单元测试）。
2. 留出小图上，τ = 1 时采样分布与精确目标的平均总变差距离 ≤ 0.20，并且不超过"起点分布到目标的距离"的一半。
3. 采样样本的平均能量与目标平均能量相差 < 10%。

### 2C：RB-small 上训练

**做什么**

- 训练设置向 DiffUCO / CAM 的 RB-small 配置看齐（同样的网络、每步图数、参数更新次数；温度退火沿用它们的做法并按 M2 的结论处理修正项）。
- 主对照（各 2 个种子）：
  - 有修正项、参考过程不完全混合（完整的 SB）；
  - 无修正项、参考过程完全混合（没有 SB 的离散 adjoint matching）。
- 参考过程的噪声强度扫 3 个值（各 1 个种子）。
- 单个 run 上限 24 GPU 小时。

**验收标准**

- **跑通**：验证锚点上 ≥ 19.5。达不到时允许 2 轮诊断（合计最多 40 GPU 小时）；仍达不到，本阶段记为失败，写明卡在哪里。
- 科学结论分档：
  - **有竞争力**：≥ 19.85（与 DiffUCO 相差 0.03 以内）。
  - **SB 是否有用**：有修正项减无修正项，逐图配对差 ≥ +0.03 且区间不含 0 为阳性。
- 报告里另外给出训练效率曲线：解质量对参数更新次数。

## 6. 风险

| 风险 | 表现 | 应对 |
|---|---|---|
| 就近配对未必更好学 | 1C 阴性 | 网络要从 x0 读出"去哪个解"，可能比学平均更难。1C 的"起点决定解的程度"指标能区分"没学会对应"和"学会了但没有带来更好的解" |
| 采样器误差累积 | 马尔可夫后验采样明显差于桥式重加噪 | 基线上 D3PM 后验采样就比 renoise 低 0.33。两种采样器都报告 |
| 有意义的 ω 范围很窄 | p 只在 0.38–0.475 之间，与基线差别小 | 1A 先量化；必要时把结论写成"在这个问题上 SB 与扩散几乎重合" |
| 扰动出来的次优解拉低质量 | 1E 的扰动组低于多解组 | 这正是"质量对好学"的权衡，如实报告；加权组用来缓解 |
| 路线 2 训练不稳定 | 2B、2C 不收敛 | 11-15 的小图实验里 DASBS 是稳定的；跨图共享和温度退火是新增的不确定因素，所以先在小图上过 2B |
| 路线 2 赶不上 CAM | 2C 低于 19.85 | CAM 是针对低温寻优简化过的；DASBS 匹配的是有限温度的分布。达不到也是有价值的结论，重点看"有无修正项"的对照 |
| 时间不够 | 3 天内做不完 | 优先级：M1 → 1A → 1B → 1C → M2 → 2A → 2B → 1E → 2C → 1D → 1F。做不完的写进报告 |
