# 总报告：薛定谔桥用于 RB-small MIS（两条路线）

（草稿，随各阶段完成补全；最终版以本文件为准。逐阶段的过程记录见 `status.md`。）

要回答的问题（plan.md §0）：薛定谔桥（SB）学到的"随机起点 → 解"的就近对应关系，能不能让模型在 RB-small 最大独立集上采样得更好？

- 路线 1：两端都有样本（起点 Bernoulli(0.5)，终点 KaMIS 多解或解加扰动），有监督，离散 SB 的静态解（Sinkhorn）加 bridge matching。
- 路线 2：终点只有能量，无监督，离散 ASBS（DASBS，Guo 等，arXiv 2602.08243）。

所有选择（配置、ω、checkpoint）只看验证锚点（验证图第 64–499 张）；测试集数字只在 1F 之后报告。
