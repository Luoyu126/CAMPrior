# 总报告：薛定谔桥用于 RB-small MIS（两条路线）

（草稿，随各阶段完成补全；最终版以本文件为准。逐阶段的过程记录见 `status.md`。）

要回答的问题（plan.md §0）：薛定谔桥（SB）学到的"随机起点 → 解"的就近对应关系，能不能让模型在 RB-small 最大独立集上采样得更好？

- 路线 1：两端都有样本（起点 Bernoulli(0.5)，终点 KaMIS 多解或解加扰动），有监督，离散 SB 的静态解（Sinkhorn）加 bridge matching。
- 路线 2：终点只有能量，无监督，离散 ASBS（DASBS，Guo 等，arXiv 2602.08243）。

所有选择（配置、ω、checkpoint）只看验证锚点（验证图第 64–499 张）；测试集数字只在 1F 之后报告。

## 4. 没做完的、建议下一步

没做完的：

- 2C 的噪声强度扫描（α = 0.25、1.0）和第二个种子没有跑：主设置没有跑通，扫描没有意义。"SB 是否有用"（sb − ml）在 RB-small 上无法判定。
- 路线 2 没有测试集数字。
- 1B 标准 4、1D 标准 2 的口径待确认（§5），结果都已按原标准记录。

建议下一步（都需要另开计划）：

- 路线 2（先让它跑通，再谈 SB 有没有用）：
  - DASBS 附录 C 的样本缓冲区：用过去较好的终点样本训练控制器，切断"采样变随机 → 目标变大 → 采样更随机"的正反馈。这是最直接针对 2C 卡点的改法。
  - 给控制器输出加上限 log Φ ≤ log(2/G)：超过的部分翻转概率已经是 1，不改变采样器，但能去掉重尾目标对梯度方向的主导；低温时配更小的学习率。
  - 用路线 1 的模型或 DiffUCO 的模型初始化控制器，从"已经接近可行"的状态开始在线训练，检验退化不动点是不是只在随机起步时才吸收。
- 路线 1：
  - 1C 和 1F 说明，在 KaMIS 多解上，"起点 → 解"的就近对应在 50 步下不带来 MIS 收益；只在 5 步时有约 +0.05。如果关心少步采样，可以专门在 1–5 步上比较（含 1 步的确定性映射），这是 SB 唯一稳定出现正效应的区间。
  - 1E 说明 SB 的收益依赖标签：标签质量参差（单解 + 扰动、k128）时为正，标签集中在好解时中性或为负。可以把"SB 能把差标签拉向近处好解"作为单独的假设，用质量可控的合成标签验证。
  - 1D 的学出来的配对与闭式配对打平；在 RB-small 上不必再做 IMF，除非换到闭式 Sinkhorn 算不动的规模。
- 1B 揭示的训练配置混杂（多卡训练比单卡低约 0.03–0.04）本身值得记下：以后所有 DIFUSCO 对比都要在同一卡数、同一每卡批量下做。
