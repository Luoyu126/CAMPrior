# 总报告：薛定谔桥用于 RB-small MIS（两条路线）

（11-26 13:10 定稿。逐阶段的过程记录见 `status.md`。）

要回答的问题（plan.md §0）：薛定谔桥（SB）学到的"随机起点 → 解"的就近对应关系，能不能让模型在 RB-small 最大独立集上采样得更好？

- 路线 1：两端都有样本（起点 Bernoulli(0.5)，终点 KaMIS 多解或解加扰动），有监督，离散 SB 的静态解（Sinkhorn）加 bridge matching。
- 路线 2：终点只有能量，无监督，离散 ASBS（DASBS，Guo 等，arXiv 2602.08243）。

所有选择（配置、ω、checkpoint）只看验证锚点（验证图第 64–499 张）；测试集数字只在 1F 之后报告。

## 3. 对 §0 问题的回答与证据强度

问题：SB 学到的"随机起点 → 解"的就近对应关系，能不能让模型在 RB-small MIS 上采样得更好？

**路线 1（两端都有样本）：学得到；50 步时不带来更好的 MIS；少步数时带来。**

1. 就近对应确实学到了。起点依赖比值：SB 约 0.965，独立配对约 1.00。ω 越大越依赖起点（ω = 1.0 时 0.87）。证据强：1C、1D、1E、1F 的所有 SB 模型都一致，并且有打乱起点的对照。
2. 标准设置（50 步 × 20 个样本取最好）下，MIS 没有提升。
   - 1F：3 + 2 个种子、800 epoch，锚点差 −0.000 [−0.024, +0.024]，测试差 +0.013 [−0.003, +0.030]。
   - 1C 的 400 epoch 也是中性。
   - 证据强：多种子、预先定的协议，区间窄到可以排除超过约 0.03 的提升。
   - 更强的对应反而有害（ω = 1.0 为 −0.049）。
3. 少步数时 SB 稳定更好。
   - 锚点 5 步：1C +0.054，1F +0.085。
   - 测试 10 步：1F +0.041。
   - 区间都不含 0。证据中等偏强：方向一致、多种子、跨验证和测试；但 5 步不是预先定的主指标。
4. 收益依赖标签（1E）。标签质量参差时 SB 更有帮助，最多 +0.089；标签已集中在好解时中性或为负。证据弱到中：每组 1 个种子，但多组方向一致。
5. 学出来的配对（1D，IMF）与闭式配对打平，没有额外收益。

最终的 SB 模型在测试集上 19.891，与 DiffUCO（19.880）、DiffUCO 多解（19.890）相当，低于 CAM（19.907）。

**路线 2（终点只有能量）：本次无法回答。** DASBS 在 RB-small 上没有跑通：锚点最好 18.209，门槛 19.5。在线 ctrl-AM 有吸收性的退化不动点，"有修正项 − 无修正项"无法比较。小图（2B）上实现是对的（总变差 0.175），但 SB 版不比无修正项的版本好（0.175 对 0.115）。

**总结**：在 RB-small MIS 上，SB 的就近配对对"多步采样的最好解"没有帮助，对"少步采样"有中等大小、可重复的帮助。

之后用户新增了阶段 E（`docs/20261126/plan_endpoint.md`）：换终点分布（最优解平台、近邻次优解、DiffUCO 或模型自身样本打磨后的解，按玻尔兹曼加权），看 SB 能否在 50 步上也带来提升。结果见 `docs/20261126/status_endpoint.md`。

## 4. 没做完的、建议下一步

没做完的：

- 2C 的噪声强度扫描（α = 0.25、1.0）和第二个种子没有跑：主设置没有跑通，扫描没有意义。"SB 是否有用"（sb − ml）在 RB-small 上无法判定。
- 路线 2 没有测试集数字。
- 1B 标准 4、1D 标准 2 的口径待确认（§5），结果都已按原标准记录。

建议下一步（都需要另开计划）：

- 路线 2（先让它跑通，再谈 SB 有没有用）：
  - DASBS 附录 C 的样本缓冲区：用过去较好的终点样本训练控制器，切断"采样变随机 → 目标变大 → 采样更随机"的正反馈。这是最直接针对 2C 卡点的改法。
  - 给控制器输出加上限 log Φ ≤ log(2/G)：超过的部分翻转概率已经是 1，不改变采样器，但能去掉重尾目标对梯度方向的主导；低温时配更小的学习率。
  - 用路线 1 的模型或 DiffUCO 的模型初始化控制器，从"已经接近可行"的状态开始在线训练，检验退化不动点是不是只在随机起步时才吸收。
- 路线 1：
  - 1C 和 1F 说明，在 KaMIS 多解上，"起点 → 解"的就近对应在 50 步下不带来 MIS 收益；只在 5 步时有约 +0.05。如果关心少步采样，可以专门在 1–5 步上比较（含 1 步的确定性映射），这是 SB 唯一稳定出现正效应的区间。
  - 1E 说明 SB 的收益依赖标签：标签质量参差（单解 + 扰动、k128）时为正，标签集中在好解时中性或为负。可以把"SB 能把差标签拉向近处好解"作为单独的假设，用质量可控的合成标签验证。
  - 1D 的学出来的配对与闭式配对打平；在 RB-small 上不必再做 IMF，除非换到闭式 Sinkhorn 算不动的规模。
- 1B 揭示的训练配置混杂（多卡训练比单卡低约 0.03–0.04）本身值得记下：以后所有 DIFUSCO 对比都要在同一卡数、同一每卡批量下做。

## 5. 需要用户或 Shengyu 决定的事

- 1B 标准 4 的基线口径：按原文（与多卡训练的已有基线比）是失败（+0.039），按配置一致的单卡基线是通过（+0.030，区间含 0）。差别来自训练配置，不是 SB 代码。

- 1C 与 1F 的基线口径：原基线是多卡训练，SB 是单卡训练；ω = 0 的 SB 代码路径单卡训练比原基线高约 0.04。主结论用配置一致的单卡 ω = 0 基线（同时报告了对原基线的差，对原基线 1C 为 +0.047，阳性）。是否认可这个口径，需要确认。

- 1D 验收标准 2（"学到的配对代价与闭式配对相差 < 10%"）偏弱：ω = 0.5 时独立配对的平均 Hamming 代价（113.7）只比闭式 SB 配对（110.3）高 3.1%，第 0 轮就满足。结果按原标准记录，另报"缩小了多少差距"。是否改标准，需要决定。

- 是否把"少步数（5–10 步）"作为 SB 的主要卖点继续做：这是路线 1 唯一稳定为正的结果，但 plan.md 的主指标是 50 步。
- 路线 2 是否值得按 §4 的建议另开计划（样本缓冲区、控制器输出上限、用路线 1 模型初始化）。
