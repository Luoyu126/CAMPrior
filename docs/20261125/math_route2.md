## 0. 记号与约定

本文沿用 DASBS 的约定，与路线 1 的 DIFUSCO 下标约定不同（换算见 §11）：

- 状态 x ∈ {0,1}^n。x^i 表示把 x 的第 i 位翻转。d(x, y) 是 Hamming 距离。
- 时间 t ∈ [0, 1]。起点 μ 在 t = 0，这里是 Uniform({0,1}^n) = Bernoulli(0.5)^n；终点 ν 在 t = 1。
- 目标 ν(x) ∝ exp(−H(x)/τ)，τ > 0 是温度。
- 参考过程 R、SB 的路径分布 P*，最小化 KL(P ‖ R)，约束 P_0 = μ、P_1 = ν。

## 1. 参考过程

**定义 [DASBS 式 (16)，N = 2]。** 每一位独立地以速率 γ_t / 2 翻转，γ_t ≥ 0 是噪声表。记 Γ(s, t) = ∫_s^t γ_u du。两种噪声表：

- 常数：γ_t = γ，Γ(s, t) = γ (t − s)；
- log-linear：γ_t = γ / (t + α)，Γ(s, t) = γ log((t + α)/(s + α))。DASBS §6 的消融（式号无，Fig. 2）用的就是它；α = 0 时 memoryless。

**命题 1.1（转移核）[DASBS 命题 B.5，N = 2]。** 区间 [s, t] 上的转移核是信号 a = e^{−Γ(s,t)} 的二元对称信道：

```
K_{s,t}(x, y) = Π_i ((1 + a)/2)^[x_i = y_i] · ((1 − a)/2)^[x_i ≠ y_i]
```

证明：单个位的生成元是 (γ_t/2)·[[−1, 1], [1, −1]]，特征值 0 和 −γ_t，所以 [s, t] 上该位保持不变的概率是 (1 + e^{−Γ(s,t)})/2。各位独立。∎

- 信号沿时间相乘：a(s, u) = a(s, t)·a(t, u)（与路线 1 的引理 1.1 相同）。
- **memoryless** 指 a(0, 1) = 0，即 Γ(0, 1) = ∞（log-linear 且 α = 0）。这时终点与起点独立。
- **对称性**（下面多次用到）：d(x^i, y) = d(x, y^i)，所以 K_{t,1}(x^i, y) = K_{t,1}(x, y^i)。这是 DASBS 式 (17)"核是加性的"在二值情形下的特例（Z_2 上翻转第 i 位就是加 e_i）。

验证：
- `test_reference_kernel_is_matrix_exponential` 与矩阵指数对照，并检查 Chapman–Kolmogorov；n ≤ 4，误差 < 1e-12。
- **逐位桥的闭式** [DASBS 命题 B.6]：给定两端，参考桥在各位上独立，P(X_t,i = 1 | x0, x1) ∝ K_{0,t}(x0_i, 1) K_{t,1}(1, x1_i)（`dasbs_exact.bridge_prob1`）。`test_per_bit_bridge_against_matrix_exponential`：20 组随机 (n, x0, x1, t)，两种噪声表，把逐位乘积与用全生成元的矩阵指数算出的 K_{0,t} K_{t,1} / K_{0,1} 逐状态对照，相对误差 < 1e-9；2A 的采样代码 `utils/dasbs.py` 的 `bridge_prob_one` 与它相差 < 1e-12。
- **memoryless**：log-linear 且 α = 0 时 Γ(0, t) = ∞，代码里直接返回无穷（信号 0），不再除以零。

## 2. SB 的势与最优速率

**定理 2.1 [DASBS 定理 3.1，式 (10)–(13)]。** 存在正函数 φ̂_0、φ_1，使得：

```
π*(x0, x1) = φ̂_0(x0) K_{0,1}(x0, x1) φ_1(x1)        （静态 SB；Schrödinger 方程组）
φ_t = K_{t,1} φ_1          （式 11，后向）
φ̂_t = K_{0,t}^T φ̂_0       （式 12，前向）
P*_t = φ_t · φ̂_t          （式 13）；边界条件 φ_0 φ̂_0 = μ，φ_1 φ̂_1 = ν
```

最优速率是

```
u*_t(x^i, x) = r_t(x^i, x) · φ_t(x^i) / φ_t(x) = (γ_t / 2) · Φ_t(x)_i     （式 10）
```

其中**控制器** Φ_t(x)_i := φ_t(x^i) / φ_t(x)。

定理 2.1 的证明见 DASBS 附录 B.2。思路是：P* 是 R 以 h_t = φ_t 做的 Doob h 变换，h 变换后的速率是 r(y, x) h(y)/h(x)。

**修正项（corrector）** Φ̂(y)_i := φ̂_1(y^i) / φ̂_1(y)。它只在 t = 1 处出现，用来把 ν 的比值拆成 φ_1 的比值（§4）。

验证：
- `test_optimal_rate_solves_forward_equation`：20 张随机小图（n = 4–8，边概率 0.2–0.6），τ ∈ [0.3, 2]，两种噪声表。在 4 个时刻检查 d/dt (φ_t φ̂_t) = U_t^T (φ_t φ̂_t)，U_t 是上式速率的生成元。逐项残差 ≤ 1e-10 × 该项各组成部分的绝对值之和。
- 一个比特的情形另有 sympy 符号验证：`test_one_bit_symbolic` (i)。

## 3. MIS 能量与带温度的目标

```
H(x) = −Σ_i x_i + λ Σ_{i<j} A_ij x_i x_j,     λ = 2（> 1，最小值点是最大独立集）
ν_τ(x) ∝ exp(−H(x)/τ)
```

**引理 3.1（能量的翻转差）[自行推导]。**

```
ΔH_i(x) := H(x^i) − H(x) = (1 − 2 x_i) · ( −1 + λ (A x)_i )
```

证明：翻转第 i 位让 x_i 变化 δ = 1 − 2x_i；只含 x_i 的项是 −x_i + λ x_i Σ_j A_ij x_j（A_ii = 0），所以变化量是 δ·(−1 + λ (Ax)_i)。∎

于是 ν(x^i)/ν(x) = exp(−ΔH_i(x)/τ)。这是一阶 oracle，每一位只需 O(度) 的计算，在 GPU 上对整批图并行。

- 读法：x_i = 0 时，加入第 i 点。若邻居里已有 k 个点在集合中，能量变化 −1 + λk：没有冲突时降低 1，有冲突时升高。x_i = 1 时符号相反。

验证：`test_mis_flip_delta`，10 张图上与直接相减对照，误差 < 1e-12。

## 4. 控制器的比值恒等式（ctrl-AM 的目标）

**命题 4.1 [DASBS 式 (18)–(21)；二值情形自行核对]。** 对任意 t ∈ [0, 1] 和 x，

```
Φ_t(x)_i = E*[ φ_1(X_1^i) / φ_1(X_1) | X_t = x ]
         = E*[ exp(−ΔH_i(X_1)/τ) / Φ̂(X_1)_i | X_t = x ]
```

证明：

1. 由式 (11) 和 §1 的对称性：

   ```
   φ_t(x^i) = Σ_y K_{t,1}(x^i, y) φ_1(y) = Σ_y K_{t,1}(x, y^i) φ_1(y) = Σ_{y'} K_{t,1}(x, y') φ_1(y'^i)
   ```

   最后一步换元 y' = y^i，这是 {0,1}^n 上的双射。

2. 两边除以 φ_t(x)。由式 (13)，P*(X_1 = y | X_t = x) = K_{t,1}(x, y) φ_1(y) / φ_t(x)，所以

   ```
   Φ_t(x)_i = Σ_y P*(X_1 = y | X_t = x) · φ_1(y^i)/φ_1(y)
   ```

3. 终点比值：φ_1 = ν / φ̂_1（边界条件），所以

   ```
   φ_1(y^i)/φ_1(y) = [ν(y^i)/ν(y)] · [φ̂_1(y)/φ̂_1(y^i)] = exp(−ΔH_i(y)/τ) / Φ̂(y)_i      （式 21）
   ```

   ν_τ 处处为正，所以每个比值都有定义。∎

**变分形式 [DASBS 式 (20)]。** 对严格凸的 f，Bregman 散度 D_f 满足 E[ξ] = argmin_c E D_f(ξ ‖ c)。所以

```
Φ* = argmin_Φ  E_t E_{(x, x1) ~ P*_{t,1}} Σ_i D_f( R(x1)_i ‖ Φ_t(x)_i ),     R(y)_i := exp(−ΔH_i(y)/τ) / Φ̂(y)_i
```

(x, x1) 的抽法：(x0, x1) 来自当前模型，x 从参考桥 R(x_t | x0, x1) 抽（DASBS 引理 B.2 式 (26)：SB 的桥等于参考过程的桥；逐位闭式见命题 B.6 和 §1）。

验证：
- `test_controller_ratio_identity`：20 张图，两种噪声表，4 个时刻。条件期望与 Φ_t 逐项的相对误差 < 1e-10。终点比值与 φ_1 的比值也逐一核对。
- `test_bridge_resampling_reproduces_sb_joint`：20 张图，从 π* 加桥抽出的 (x_t, x1) 联合等于 φ̂_t(x) K_{t,1}(x, x1) φ_1(x1)，逐项相对误差 < 1e-10。这一项两边用同一个核函数，主要检查代数；桥本身与矩阵指数的对照见 §1。
- 一个比特的 sympy 验证：`test_one_bit_symbolic` (ii)。

## 5. 修正项的比值恒等式（corr-DM 的目标）

**命题 5.1 [DASBS 式 (25)；二值情形自行核对]。** 对任意 t ∈ [0, 1) 和 y，

```
Φ̂(y)_i = E*[ K_{t,1}(X_t, y^i) / K_{t,1}(X_t, y) | X_1 = y ]
```

证明：由式 (12)，φ̂_1(z) = Σ_x K_{t,1}(x, z) φ̂_t(x)。所以

```
φ̂_1(y^i)/φ̂_1(y) = Σ_x [K_{t,1}(x, y^i)/K_{t,1}(x, y)] · K_{t,1}(x, y) φ̂_t(x) / φ̂_1(y)
```

而由 P*(x_t, x_1) = φ̂_t(x_t) K_{t,1}(x_t, x_1) φ_1(x_1) 和 P*_1 = φ_1 φ̂_1，得 P*(X_t = x | X_1 = y) = φ̂_t(x) K_{t,1}(x, y) / φ̂_1(y)。∎

**二值闭式 [自行推导]。** 核的比值只看第 i 位，记 a = e^{−Γ(t,1)}：

```
K_{t,1}(x, y^i) / K_{t,1}(x, y) = (1 − a)/(1 + a)   若 x_i = y_i
                                = (1 + a)/(1 − a)   若 x_i ≠ y_i
```

所以 Φ̂(y)_i 只依赖"给定终点 y，X_t 的第 i 位与 y_i 不同的概率" q_i(y, t)：

```
Φ̂(y)_i = (1 − q_i) (1 − a)/(1 + a) + q_i (1 + a)/(1 − a)
```

- 这个式子对任何 t ∈ [0, 1) 成立。a → 1（t → 1）时两项分别趋于 0 和 ∞，估计的方差变大，所以训练时 t 不应取得离 1 太近。
- memoryless 的参考过程取 t = 0 时 a = 0，比值恒为 1，修正项恒为 1（与 §7 的结论一致）。

**取值范围 [自行推导]。** 由上式，Φ̂(y)_i 是 (1 − a)/(1 + a) 与 (1 + a)/(1 − a) 的凸组合，取 t = 0、a = a(0, 1)：

```
(1 − a)/(1 + a) ≤ Φ̂(y)_i ≤ (1 + a)/(1 − a)
```

对精确的 SB 和训练中的任意耦合都成立（只用到"终点给定时 X_0 的条件分布"）。log-linear γ = 1、α = 0.5 时 a = 1/3，范围是 [0.5, 2]。网络可以直接把输出限制在这个区间里。

验证：`test_corrector_ratio_identity`，20 张图，两种噪声表，t ∈ {0, 0.3, 0.7}，逐项相对误差 < 1e-10；一个比特的 sympy 验证 (iii)。

## 6. 回归比值本身，不回归它的对数

**结论 [DASBS 式 (20)、(23) 用 Bregman 散度的原因；自行补充反例]。** Bregman 散度的最小值点是比值的条件均值 E[ξ]。如果改成回归 log ξ（例如对 log 比值做平方误差），最小值点变成 exp(E[log ξ])。由 Jensen 不等式 exp(E[log ξ]) ≤ E[ξ]，只要 ξ 在给定条件下不是常数就严格小于。所以不动点不是 SB。

- **一个比特的显式数值**（§12 的例子，`test_cam_counterexample_one_bit`）：
  - 正确的速率倍率 = E[ξ] = 0.8131；
  - 回归对数得到 exp(E[log ξ]) = 0.1967。
- **对照实验**（下表是 n = 3 的图，τ = 0.7，常数噪声表 γ = 1.5；`m2_experiments.txt` 第 3 节）。`test_wrong_versions_fail` 在 3 张图（n = 3、4、4，τ = 0.7、0.5、1.0）× 两种噪声表上都检查：正确版本同网格 4e-5 到 1.4e-4；控制器回归 log 比值 0.11–0.16，CAM 标签同样在 100 倍以上；修正项回归 log 比值 1.2e-2 到 6.5e-2（正确的交替 < 1e-6）；不用修正项 7e-4 到 3.9e-2（用 SB 的修正项时 < 1e-12）：

| 版本 | 终点与 ν 的总变差 |
|---|---|
| 正确的交替，400 轮 | 3.5e-18 |
| 控制器回归 log 比值（其余正确，时间网格 50 段） | 大于正确版本同网格结果的 100 倍 |
| 修正项回归 log 比值，400 轮 | 2.5e-2 |
| 非 memoryless 参考过程但不用修正项（修正项恒为 1） | 1.8e-2 |
| 同上但参考过程接近 memoryless（γ = 40） | < 1e-8（不用修正项也对） |
| 参考过程严格 memoryless（log-linear，α = 0），不用修正项 | < 1e-12（`test_memoryless_reference_needs_no_corrector`，6 张图） |

**真实规模下标签的大小 [自行推导；复核意见 10]。** 控制器的标签是 exp(−ΔH_i(X_1)/τ) / Φ̂(X_1)_i。X_1 的第 i 位为 1、有 k 个邻居也在集合中时，ΔH_i = 1 − λk，标签是 exp((λk − 1)/τ) / Φ̂。

- 训练早期 X_1 接近参考过程的终点（约为 Bernoulli(0.5)），RB 图上 k ≈ 10 很常见：τ = 1 时标签约 e^19 ≈ 1.8e8，τ = 0.1 时 e^190，float32 在指数超过 88 时溢出，float64 在 709。
- 所以标签和损失都要在对数空间计算。广义 KL 散度 D(a ‖ b) = a (log a − log b) − a + b 可以直接用 log a、log b 写出（2A 的 `ratio_bregman` 就是这样，并用 float64）；溢出时报错而不是截断。
- 截断标签（例如 min(标签, C)）会把不动点从 E[ξ] 变成 E[min(ξ, C)]，与 §6 的 Jensen 论证同理，不再是 SB。2C 若因数值原因需要截断，必须作为一个偏差记录，并在小图上量出它的影响。
- DASBS 附录 C 也用广义 KL 作为 Bregman 散度（原文第 4007 行）。

## 7. 交替更新就是 IPF（Sinkhorn）

DASBS 的训练交替两步：固定修正项，用 ctrl-AM 拟合控制器；再用当前控制器生成的样本，以 corr-DM 拟合修正项。

**命题 7.1 [DASBS 定理 5.2；势函数形式自行推导]。** 设当前修正项对应 φ̂_1。

1. **ctrl-AM 的不动点**：控制器拟合到不动点时，模型的路径分布是 R 以终点函数 φ_1 = ν / φ̂_1 做的 h 变换，从 μ 出发：

   ```
   P(x0, x1) = μ(x0) K_{0,1}(x0, x1) φ_1(x1) / φ_0(x0),     φ_0 = K_{0,1} φ_1
   ```

   这是前向半桥（只约束起点）。代码：`forward_half_bridge`。

   注意：这是"用当前模型的样本回归、再用新模型重新采样"这一迭代的**不动点**，不是一次回归的结果。

2. **corr-DM 的结果**：对上面的 P，按命题 5.1 的同样推导，P(x_t, x_1) = ψ_t(x_t) K_{t,1}(x_t, x_1) φ_1(x_1)，其中 ψ_t = K_{0,t}^T (μ / φ_0)。所以 corr-DM 给出的比值是

   ```
   φ̂_1'(y^i)/φ̂_1'(y),     φ̂_1' = K_{0,1}^T ( μ / K_{0,1} φ_1 )
   ```

   与 t 无关。

3. 合起来：φ̂_1 → φ_1 = ν/φ̂_1 → φ̂_0 = μ/(K φ_1) → φ̂_1' = K^T φ̂_0。**这正是 Sinkhorn 迭代的一轮**。核 K_{0,1} 处处为正（a(0,1) < 1 且 n 有限），所以交替收敛到 SB（Sinkhorn 1967；Franklin & Lorenz 1989；DASBS 引用的 IPF 理论）。∎

**推论 7.2。**

- **修正项初始化为 1 与控制器初始化为 1 等价**，在 μ 均匀时成立 [DASBS 命题 B.12]：控制器为 1 时模型就是 R，修正项一步得到 K^T μ，这仍是均匀的，比值恒为 1。
- **memoryless 时不需要修正项**：K_{0,1}(x0, x1) 与 x0 无关，所以 φ̂_1' 是常数，修正项恒为 1，第一轮就是 SB。
- **当耦合恰好是前向半桥时**，corr-DM 的比值场能积分成一个势（它就是 φ̂_1' 的比值），把比值还原成势没有不一致。`test_alternation_converges_to_sb` 检查了这一点（不一致 < 1e-9）。对一般的模型耦合，corr-DM 的均值 Σ_x0 P(x0 | y) K_{0,1}(x0, y^i)/K_{0,1}(x0, y) 一般不是梯度场。DASBS 直接输出比值，不还原成势，所以 2B/2C 应当测量比值场沿闭合回路的不一致，作为"离不动点多远"的诊断。

验证：
- `test_alternation_stage_is_one_sinkhorn_step`：命题 7.1 的第 2 点，20 张图，任意修正项、t ∈ {0, 0.4, 0.9}，逐项相对误差 < 1e-9。
- `test_sb_is_fixed_point_of_both_maps`：20 张图，SB 是两个映射的共同不动点。
- `test_alternation_converges_to_sb`：20 张图，两种噪声表，从全 1 修正项出发，400 轮后终点总变差 < 1e-6。这里控制器一步用的是闭式的前向半桥。
- `test_am_fixed_point_for_any_frozen_corrector`：命题 7.1 第 1 点对**非 SB 的修正项**（全 1 和随机）同样成立：阻尼的控制器迭代收敛到对应的前向半桥，配对的总变差 8e-6 到 8e-5（J = 100 的时间离散误差），而这个半桥与 SB 的配对相差 7e-4 到 0.34，大 5 倍以上。2 张图 × 两种噪声表。
- `test_alternation_with_iterated_controller`：交替时控制器用阻尼迭代求（不用闭式），修正项用 corr-DM。6 轮里每一轮的终点都与精确交替相差 < 5e-4，最后与 ν 相差 < 5e-4（J = 50 的时间离散误差）。

**控制器不动点迭代的阻尼 [自行发现]。** 用表格形式做"回归—重新采样"的控制器迭代：
- 不加阻尼会振荡、不收敛：200 轮后每轮的变化量仍大于 1，是周期 2 的振荡（`test_undamped_am_iteration_oscillates`，两种噪声表）；
- 取步长 η = 0.5 的阻尼后收敛到前向半桥（`test_am_iteration_reaches_fixed_point`）；
- 剩余误差来自分段常数的时间离散，按 1/J² 下降（J = 50 → 100，误差比 3.5–4.5）。

**对训练的含义**：每一阶段控制器的更新幅度要小（小学习率、或者对旧模型做插值），否则可能来回摆动。网络 + SGD 天然带阻尼，但重新采样的频率与学习率需要一起调。DASBS 附录 C（原文第 4005–4010 行）的做法与此一致：模型参数取指数滑动平均（衰减 0.9999），保留一个样本缓冲区（512 或 4096 对），每 10 或 20 次梯度更新才用当前控制器重新采样一批 128 对。

**收敛速度没有可迁移的保证 [复核意见 11]。** Sinkhorn 的收敛是定性的。二元信道核的 Birkhoff 收缩系数是 tanh(n · log((1 + a)/(1 − a)) / 2)：a = 1/3 时 n = 8 为 0.992，n = 250 时与 1 只差 O(e^{−173})。所以最坏情况的界在真实规模上没有意义，小图上测到的 4–6 轮不能外推。DASBS 本身只训练 5 个阶段（附录 C），并且报告：在临界和低温下用均匀的 μ"效果不好"，改用零温分布作为 μ（原文第 4011–4013 行）。对 MIS 而言，低 τ、μ = Bernoulli(0.5) 正是这种情形；2C 需要把阶段数和起点分布当作要验证的量，而不是默认 5 个阶段就够。

## 8. 问题 2：跨图共享网络

**命题 8.1 [自行推导]。** 设训练图 G 从有限集合上的某个分布 ρ(G) > 0 抽取，控制器网络 Φ_θ(x, t; G) 以图为输入，损失是

```
L(Φ) = E_{G~ρ} E_t E_{(x, x1) ~ P^G_{t,1}} Σ_i D_f( R_G(x1)_i ‖ Φ(x, t; G)_i )
```

在函数空间（不受网络容量限制）中，L 的最小值点在每个 (G, t, x) 处等于 E[R_G(X_1)_i | X_t = x, G]，即每张图各自的最优控制器。

证明：对每个固定的 G，内层期望是 §4 的单图问题。因为 G 是输入，不同 G 的 Φ(·; G) 是函数空间里不同的坐标，L 是各 G 的损失按 ρ(G) 加权的和，可以逐个 G 分别最小化。Bregman 散度的条件均值性质给出每张图的最小值点。∎

- 修正项、以及交替的每一轮，都同理逐图成立。各图的 IPF 互不干扰，网络容量是它们之间唯一的耦合。
- **前提是网络能区分目标不同的输入 [复核意见 8]。** 上面的论证在函数空间里把每个 (G, x, t, i) 当作独立坐标。消息传递 GNN 的区分能力不超过 1-WL 检验：两张 1-WL 不可区分、但目标不同的图，GNN 在对应输入上必然给出相同输出，最小值点变成两者按出现频率的混合，对哪张图都不是 SB。反例（复核者 `runs/scratch/m2_review/check4.py`）：两个三角形与 6-环，x = 0 时所有点的 WL 颜色相同，但精确控制器不同（τ = 0.3，t = 0.9 时 Φ_0 = 7.11 对 8.07；t = 0 时 0.996 对 1.188）。对策：随机节点特征或位置编码。2B 的小图族里要放这样的图对，检查它们的误差。
- ρ(G) 的具体形式（均匀、按大小加权）不改变最小值点，只改变有限容量下的取舍。
- **样本缓冲区必须按图组织**：(x0, x1) 必须来自当前模型在**同一张图**上的采样，R_G 必须用同一张图的能量和修正项。若把 A 图的终点配上 B 图的能量，条件期望就不对。
- **如果图不是输入**（或网络无法区分两张图），最小值点变成 Σ_G P(G | x, t) E[R_G | x, G]，即各图最优值的混合，对任何一张图都不是 SB。GNN 以图为输入只是必要条件，还需要上一条的区分能力。

## 9. 问题 3：训练中的温度退火

**结论 [自行推导 + 数值]。**

1. τ 改变时 ν_τ 改变，SB 的两个势都会变，修正项也要变。改变后如果修正项不重新拟合，控制器的不动点就是"新 ν 配旧修正项"的前向半桥，终点偏离 ν_τ'。
2. 数值（n = 8 的图，log-linear 噪声表 γ = 1，α = 0.5，τ 从 2.0 几何下降到 0.3 共 8 档；`m2_experiments.txt` 第 2 节）：
   - 温度改变后不重新拟合修正项，终点总变差 5.3e-3 到 2.4e-2（7 次改变；表中第一行 3.0e-2 是全 1 初始修正项，不是温度改变）；
   - 从上一档温度的修正项热启动，达到总变差 < 1e-4 需要 3–5 轮交替，与从全 1 冷启动（4–6 轮）相当或略少；
   - 连续退火：200 档温度、每档只做 1 轮交替。第 0 档是从全 1 修正项冷启动（3.0e-2）；第 1 档 2.2e-3，从第 2 档起与当前目标的总变差 ≤ 1.1e-3；退火结束后在最终温度再做 5 轮，降到 3e-8，10 轮 1.6e-12。
   - 独立推导（§15）另外量到：修正项过期带来的总变差对温度倒数的变化 Δβ 是一阶的（n = 8，常数 γ = 1，总变差 / Δβ ≈ 7e-3，Δβ 从 0.025 到 0.4 基本不变）；γ = 3 时过期修正项的总变差 ≤ 2.4e-4。
3. **建议**：退火可以和交替同时进行，但必须一直更新修正项，不能冻结；温度降得足够慢，使每档的变化小于一轮交替能纠正的量；到最终温度后再做若干轮交替。

**适用范围**：这里每轮的控制器取精确的不动点。用网络时控制器每轮离不动点还有距离（§7 的阻尼），实际需要的轮数会更多。这一点在 2B 用小图上的网络训练核实。

## 10. 问题 4：50 步的离散时间采样

DASBS 用 τ-leaping 采样 [DASBS 命题 B.7，附录 B.6]：在 [t, t + h] 上冻结 Φ_t(x)，每一位独立地以概率 Γ(t, t+h)/2 · Φ_t(x)_i 翻转。下面用**精确的**控制器，精确计算采样器终点的分布（`tau_leaping_marginal`），所以误差只来自时间离散。

**数值**（3 张图，n = 7–8，τ ∈ {1, 0.5, 0.3}，常数 γ = 1.5 与 log-linear γ = 1、α = 0.5；`m2_experiments.txt` 第 1、4、5 节）：

- 总变差随步数单调下降，约按 1/N（每翻倍约减半）：一阶方法。
- **50 步时总变差 0.0078–0.0375**（均匀时间网格）。起点与 ν 的总变差是 0.56–0.92。独立推导（§15）在另外的设置下量到的阶数也是 1（0.95–1.1）。
- **单个位的翻转概率接近 1，来自最后一步**：最大的未截断单位翻转概率出现在最后一步、ν(x) ≈ 0 的状态上（实测最大 1.00007，所以截断本身几乎不起作用）。这些状态必须在剩余时间内离开，φ_{1−h}(x) ≈ (Γ_h/2) Σ_j φ_1(x^j)。
- **但问题在于各位独立地翻转，而不是截断 [复核意见 9]。** 最后一步上"各位翻转概率之和"的最大值是 1.2–4.0（`m2_experiments.txt` 第 1 节最后一列）：精确的过程只需要离开这个状态一次（翻一位），τ-leaping 却让各位独立地翻，可能一位都不翻（这个状态上的概率 0–0.21），也可能同时翻好几位。冲突状态因此可能留到终点。这部分误差已经包含在上面的总变差里；在 n ≈ 250 时会表现为终点含冲突的集合。**对 2C 的要求**：报告原始终点的可行比例和冲突数，评测时用贪心解码（与 DiffUCO / CAM 相同），并把解码前后的结果分开报告。
- **步进规则**：一阶规则（DASBS）好于"1 − exp(−速率·h)"。后者在所有设置下误差大 1.5–3.2 倍（第 4 节，实测 1.47–3.22）。"1 − exp" 是"至少跳一次"的概率，不是两状态链净翻转的概率；它为什么更差这里没有单独验证。保留 DASBS 的规则。
- 独立推导给了一个保证概率合法的变体：把第 i 位当作其他位冻结的精确两状态链，p = Φ²/(1 + Φ²) · (1 − exp(−Γ (Φ + 1/Φ)/2))，也是一阶，误差常数大 1.3–1.6 倍。log-linear 且 α 很小时，t = 0 附近的 Γ(0, h) 很大（γ = 3，α = 0.01，25 步时首步线性翻转概率 2.41），需要步长条件或按 Γ 均匀的网格；memoryless（α = 0）时首步就是均匀重抽（`tau_leaping_marginal` 已这样处理）。
- **时间网格**：网格在 t = 1 附近加密（t = 1 − (1 − s)²）时，50 步的总变差为 0.006–0.013（同样设置下均匀网格 0.008–0.038），最多降为均匀网格的 1/2.9（第 5 节，常数噪声表、τ = 0.3）。log-linear 噪声表在 τ = 1 时几乎没有改进（它本身已在 t 小时速率大、t 大时速率小）。控制器在 t → 1 附近变化最快，所以把步子放在那里更划算。

**对 2C 的含义**：
- 小图上 50 步的误差约 1%–4%。真实图 n ≈ 250，每一步有更多位同时翻转，τ-leaping 丢掉的相关性随维数增加，误差可能更大。
- 2C 应该在 t = 1 附近加密网格，并报告 50、100、200 步的结果，看是否已收敛。

## 12. 与 CAM 标签的关系

本节重新核对本机推导记录（`sb_worktrees/CAM/docs/20261114/sb_mis_dasbs_cam_discussion.md` §10–§11）。

记 F = H/τ + log φ̂_1（加入修正项后的终点代价，使 φ_1 = ν/φ̂_1 ∝ e^{−F}，于是 exp(−Δ_i F) = exp(−ΔH_i/τ)/Φ̂_i，与 §4 一致，也与 DASBS 定理 3.2 的 g = log(φ̂_1/ν) 一致），Δ_i F(y) = F(y^i) − F(y)，V_t = −log φ_t。按 §4，精确的"adjoint"是

```
Δ_i V_t(x) = −log E*[ exp(−Δ_i F(X_1)) | X_t = x ]
```

**CAM 式的候选标签**：沿用 CAM 的符号传播，

```
Y_i = s_i(t,1) · Δ_i F(X_1),     s_i(t,1) = +1（X_t,i = X_1,i），−1（否则）
```

**偏差分解 [自行推导，代数恒等式]。** 条件于 X_t = x，记 Δ = Δ_i F(X_1)：

```
E[s_i Δ] − Δ_i V_t(x) = E[(s_i − 1) Δ]                 （符号传播的差别，符号不定）
                       + ( E[Δ] + log E[e^{−Δ}] )      （普通平均与指数平均的差别，由 Jensen ≥ 0）
```

一般不为零。这是按两种信号的定义做的代数，不是 CAM 论文里的公式。

**一个比特的反例（重新核对，`test_cam_counterexample_one_bit`）。** τ = 1，F(0) = 0，F(1) = 2，剩余时间内参考过程的信号 e^{−2}（每个方向速率 1），当前状态 x_t = 0：

| | 数值 |
|---|---|
| P*(X_1 = 0 \| X_t = 0) | 0.90656 |
| 精确倍率 φ(1)/φ(0) = DASBS 标签的条件均值 | 0.81312 |
| 精确 adjoint Δ V | 0.20688 |
| CAM 标签：两个终点上都是 +2，均值 2，对应倍率 e^{−2} | 0.13534 |
| 回归 log 比值得到的倍率 | 0.19667 |

- CAM 标签恒为 2，与 X_1 无关：取 X_1 = 0 时符号 +1、Δ = +2；取 X_1 = 1 时符号 −1、Δ = −2。所以它不可能等于随终点分布而变的精确 adjoint。
- 这个例子针对"有限温度下 matching 的不动点是否正确"，不是 MIS 的性能实验。
- 把修正项固定为 SB 的修正项、只迭代控制器（`test_wrong_versions_fail` (b)，不是完整的交替），用 CAM 符号标签代替 DASBS 标签，终点总变差大于正确版本 100 倍以上（3 张图 × 两种噪声表）。
