# 路线 1 的数学：均匀分布与有限标签集之间的薛定谔桥（阶段 M1）

对应 `plan.md` §2.1、§4 M1。实现：`cam/utils/sb_coupling.py`；测试：`cam/tests/test_sb_coupling.py`。

每个结论都标明来源：**[标准]** 指教科书或文献里的已知结果（给出处），**[推导]** 指本文按定义推出的结果。

## 0. 记号

- 状态 x ∈ {0,1}^n。|x| 是取 1 的位数，x ∧ s 是按位与，d(x, s) 是 Hamming 距离。恒等式 d(x, s) = |x| + |s| − 2|x ∧ s|。
- 下标 k = 0, 1, …, T 沿用 DIFUSCO 代码的约定：**k = 0 是数据端，k = T 是噪声端**。
  - 数据端的状态记作 y，取值于一张图的标签 s_1, …, s_M（互不相同），目标权重 π1(m) > 0，Σ π1(m) = 1。标签可以大小不同，π1 可以不均匀。
  - 噪声端的状态记作 z，目标分布 π0 = Uniform({0,1}^n) = Bernoulli(0.5)^n。
  - 中间状态记作 x_k；x_0 = y，x_T = z。
- 二元对称信道：信号 a ∈ [0, 1] 的信道 K_a 把每一位独立地以概率 (1 − a)/2 翻转：

```
K_a(x | y) = Π_i ((1+a)/2)^[x_i = y_i] · ((1−a)/2)^[x_i ≠ y_i]
```

  它关于 (x, y) 对称：K_a(x | y) = K_a(y | x)。

## 1. 参考过程

**定义。** 取信号表 1 = a_0 > a_1 > … > a_T ≥ 0。参考过程 R 是 {0,1}^n 上的马尔可夫链：

- 从数据端到下标 k 是信道 K_{a_k}；
- 从下标 k 到下标 l > k 是信道 K_{a_l / a_k}。

**引理 1.1（信道的复合）[推导]。** K_b 接 K_c 等于 K_{bc}。

证明：每一位独立，只看一位。经过两个信道后该位保持原值，当且仅当翻转了偶数次：

```
P(不变) = (1+b)/2 · (1+c)/2 + (1−b)/2 · (1−c)/2 = (1 + bc)/2
```

正是信号 bc 的信道。∎

所以上面的定义自洽：0 → k → l 的信号是 a_k · (a_l / a_k) = a_l。整条链从数据端到噪声端是 K_{a_T}，总翻转概率 p = (1 − a_T)/2。

**R 的初始分布。** 取 R 在数据端（k = 0）的边缘为均匀分布。对称信道保持均匀分布不变，所以 R 在每个下标上的边缘都是均匀分布。（a_T > 0 时 K_{a_T} 可逆，"噪声端取均匀"与"数据端取均匀"等价；a_T = 0 时噪声端的边缘总是均匀的，必须在数据端指定。）由 R 的时间反演用的是同样的对称信道。SB 只依赖 R 的桥（给定两端的条件过程），与初始分布的选取无关：初始分布只让 KL 差一个常数，并被吸收进势函数 g（由引理 2.1 直接得到）。这里取均匀只是为了让写法对称。**[推导]**

记 R_{0T}(y, z) = 2^{−n} K_{a_T}(z | y) 为 R 的两端联合分布。

**a_T 的含义。**

- a_T = 0：参考过程在噪声端完全混合（DASBS 称为 memoryless），两端独立。
- a_T > 0：两端相关，SB 的配对才可能和独立配对不同（见 §8）。

## 2. 静态 SB：配对的形式

**问题。** 在所有边缘分别为 π0（噪声端）和 π1（数据端）的路径分布 P 中，最小化 KL(P ‖ R)。

**引理 2.1（分解）[标准]。** 对任意路径分布 P，

```
KL(P ‖ R) = KL(P_{0T} ‖ R_{0T}) + E_{P_{0T}} [ KL( P(· | y, z) ‖ R(· | y, z) ) ]
```

（KL 的链式法则，即对两端取条件分解；Léonard 2014 的 survey 在 §2 给出，记作 "additive property"。条目编号未能对照原文核实，以内容为准。）第二项取 P(· | y, z) = R(· | y, z) 时为 0，所以 SB 等于"静态问题的解 π* 配上参考过程的桥"：

```
P*(路径) = π*(y, z) · R(路径 | y, z)，   π* = argmin { KL(π ‖ R_{0T}) : π 的两个边缘为 π1、π0 }
```

**定理 2.2（静态解的形式、存在与唯一）[标准，有限空间特例]。** 状态有限，并且 R_{0T} 在 supp(π1) × {0,1}^n 上处处为正（a_T < 1 时成立）。这时静态问题有唯一解，形式为

```
π*(s_m, z) = f(z) · K_{a_T}(z | s_m) · g_m
```

f、g 为正数，在 "f → c·f，g → g/c" 的意义下唯一。它们由 Sinkhorn 迭代求出，迭代收敛（Sinkhorn 1967；Franklin & Lorenz 1989 给出线性收敛）。

证明要点：可行集非空（独立配对可行，KL 有限）、凸、紧；KL 严格凸，所以最小值唯一。最小值点在 supp(π1) × {0,1}^n 上处处为正：x log x 在 0 处的导数是 −∞，从边界点往处处为正的独立配对 π0 ⊗ π1 方向移动会严格减小 KL（Csiszár 1975）。在内部对边缘约束写拉格朗日函数，得到 log π* = log R_{0T} + φ(z) + ψ(y)，这就是上面的乘积形式。反过来，任何这种形式的配对都是最优的：对任何可行 π，KL(π ‖ R_{0T}) = KL(π ‖ π*) + 常数。∎

**推论 2.3（条件分布）[推导]。** 对 m 归一化，f(z) 被消掉：

```
π*(y = s_m | z) = g_m K_{a_T}(s_m | z) / Σ_{m'} g_{m'} K_{a_T}(s_{m'} | z)
```

**推论 2.4（用重合数写的闭式）[推导]。** 由信道的定义，

```
log K_a(s | z) = n log((1+a)/2) − ω_a · d(z, s)，   ω_a = log((1+a)/(1−a))
```

代入 d = |z| + |s| − 2|z ∧ s|，只依赖 z 的项在归一化时消掉：

```
π*(y = s_m | z) ∝ g_m · exp( −ω |s_m| + 2ω |z ∧ s_m| )，   ω = ω_{a_T} = log((1−p)/p)
```

- **就近的含义**：在 g 一样时，选中概率随起点 z 与标签重合的点数指数增长。所有标签一样大时，−ω|s_m| 也可以并入 g。
- **ω 是 Hamming 代价的强度**：等价地，π* 是代价为 ω·d(z, y) 的熵正则最优传输（下面的引理 2.5）。

**引理 2.5（熵正则 OT 的等价形式）[推导]。**

```
KL(π ‖ R_{0T}) = E_π[ω · d(z, y)] − H(π) + 常数
```

其中常数只依赖 n、a_T 和固定的边缘。证明：log R_{0T}(y, z) = −n log 2 + n log((1+a_T)/2) − ω d(z, y)，代入 KL 的定义即得。∎

**Sinkhorn 的具体做法（代码 `sinkhorn`）。** 只迭代标签一侧：

```
P(m | z)  = softmax_m( log g_m + log K_{a_T}(s_m | z) )
marg(m)   = Σ_z π0(z) P(m | z)
log g_m  ← log g_m + log π1(m) − log marg(m)
```

噪声端的边缘由每行的 softmax 归一化自动满足。这就是 Sinkhorn 迭代在 f 一侧取精确解后的形式。

## 3. 动态 SB：给定中间状态时标签的后验

**定理 3.1 [推导]。** 对 0 < k < T，在 P* 下

```
P*(y = s_m | x_k = x) = g_m K_{a_k}(s_m | x) / Σ_{m'} g_{m'} K_{a_k}(s_{m'} | x)
```

并且 P*(y | z, x_k) = P*(y | x_k)，即给定 x_k 后，y 与 z 条件独立。

证明：由引理 2.1，联合分布是

```
P*(s_m, x_k, z) = π*(s_m, z) · R(x_k | y = s_m, z)
```

由 R 的马尔可夫性和引理 1.1，参考过程的桥是

```
R(x_k | y, z) = K_{a_k}(x_k | y) · K_{a_T/a_k}(z | x_k) / K_{a_T}(z | y)
```

代入定理 2.2 的形式，K_{a_T}(z | s_m) 约掉：

```
P*(s_m, x_k, z) = f(z) · g_m · K_{a_k}(x_k | s_m) · K_{a_T/a_k}(z | x_k)
```

它分解成"只含 (m, x_k) 的因子"乘"只含 (x_k, z) 的因子"，所以给定 x_k 时 m 与 z 条件独立。对 z 求和，再对 m 归一化，得到结论；最后用 K 的对称性把 K(x | s) 写成 K(s | x)。∎

**推论 3.2（训练目标）[推导]。** 节点上的交叉熵损失 E[ −y_i log p_i − (1 − y_i) log(1 − p_i) ]，在给定 (x_k, k) 时的最小值点是 p_i = P*(y_i = 1 | x_k)，因为交叉熵对目标是线性的。因此网络的回归目标是

```
E*[y | x_k] = Σ_m w_m(x_k) s_m，   w_m(x) = softmax_m( log g_m − λ_k |s_m| + 2 λ_k |x ∧ s_m| )，   λ_k = ω_{a_k}
```

有两种等价的训练目标：

- **硬目标**：把按 w 抽到的那个标签当目标；
- **软目标**：直接用 E*[y | x_k] 当目标。

两者的最小值点相同，软目标的方差更小（Rao–Blackwell）。这与现有软目标（`docs/20261116/difusco_sota_soft_labels.md` §2.3）的论证相同，只是多了 g_m，而且信号表在噪声端不归零。

**推论 3.3（训练样本的抽法）[推导]。** 下面的步骤得到的 (x_k, y) 正好服从 P* 在下标 k 的联合分布：

1. z ~ Bernoulli(0.5)^n；
2. m ~ π*(· | z)（推论 2.3）；
3. x_k ~ R(x_k | y = s_m, z)（§4，逐位独立）。

证明：(z, m) 服从 π*，再接上参考过程的桥，就是引理 2.1 的分解。∎

k = T 时 x_T = z，网络在纯噪声端的输入就是起点本身。

## 4. 参考过程的桥：逐位闭式

**命题 4.1 [推导]。** 给定 y、z，桥 R(x_k | y, z) 的各位相互独立，每一位为

```
P(x_k,i = b | y_i, z_i) ∝ K_{a_k}(b | y_i) · K_{a_T/a_k}(z_i | b)
```

（代码 `bridge_prob1`。）

证明：定理 3.1 证明中的桥公式对各位都是乘积。∎

**边界情形。**

- k = 0（a_0 = 1）：x_0 = y。
- k = T（a_T/a_T = 1）：x_T = z。
- a_T = 0：第二个因子是常数 1/2，桥退化为前向边缘 K_{a_k}(· | y)，与 z 无关。这正是现有 DIFUSCO 的加噪方式。

## 5. 两种采样器

两种采样器都从 x_T = z ~ Bernoulli(0.5)^n 出发，依次走 k = T, T−1, …, 1。设 Ŵ(y | x_k) 是对 P*(y | x_k) 的近似：用精确值时下面的结论严格成立；网络给出的是逐位边缘，见本节末。

下面写的是相邻下标 k → k−1。推理时实际走的是下标的一个递减子序列（跳步，例如 50 → 49 → … 或 50 → 40 → …），命题 5.1、5.2 对任意递减子序列同样成立：参考过程限制在子序列上仍是同类的信道链（引理 1.1），证明原样适用。

**采样器 A（马尔可夫后验）**

```
x_{k−1} ~ Σ_y Ŵ(y | x_k) · R(x_{k−1} | x_k, y)
```

**命题 5.1 [推导]。** 用精确后验时，A 的整条链与 P* 同分布；特别地，每个下标的边缘都正确，终点服从 π1。

证明：P*(路径) = π*(y, z) R(路径) / R_{0T}(y, z) = 2^n f(z) g(y) R(路径)，即参考过程乘上只依赖两个端点的函数（h 变换）。马尔可夫过程的 h 变换仍是马尔可夫过程，所以 P* 是马尔可夫的。它从 k 到 k−1 的转移是

```
P*(x_{k−1} | x_k) = Σ_y P*(y | x_k) · P*(x_{k−1} | x_k, y)
```

而 P*(x_{k−1} | x_k, y) = R(x_{k−1} | x_k, y)：P* 给定 y 后是参考过程在 z 和 y 之间的桥的混合，在参考过程的马尔可夫性下，再给定 x_k，x_{k−1} 只依赖 (x_k, y)。∎

R(x_{k−1} | x_k, y) = K_{a_{k−1}}(x_{k−1} | y) · K_{a_k/a_{k−1}}(x_k | x_{k−1}) / K_{a_k}(x_k | y)，正是 D3PM 的后验公式。所以**现有的 `categorical_posterior` 换成 §6 的信号表（`signal_to_Q_bar(a, as_numpy=True)`，与 `CategoricalDiffusion.Q_bar` 同为 numpy 数组）后就是采样器 A**，采样公式不需要改。测试 `test_categorical_posterior_is_sampler_A` 直接调用 `solvers/difusco.py` 里的这个函数，在 a_T = 0.3 的信号表上与逐位的 A 一致（< 1e-5，函数内部是 float32），包括跳步。

**采样器 B（以起点为端点的桥式重加噪）**

```
x_{k−1} ~ Σ_y Ŵ(y | x_k) · R(x_{k−1} | z, y)，   z 是这条链的起点 x_T
```

**命题 5.2 [推导]。** 用精确后验时，对每个 k，B 产生的 (z, x_{k−1}) 联合分布等于 P* 在 (T, k−1) 上的联合分布，终点 (z, y) 服从 π*，终点 y 服从 π1。B 的整条链一般不与 P* 同分布（x_k 与 x_{k−1} 的联合可能不对）。

证明：对 k 归纳。设 (z, x_k) 的联合是 P*(z, x_k)（k = T 时 x_T = z，成立）。那么 B 产生的

```
P(z, x_{k−1}) = Σ_{x_k} P*(z, x_k) Σ_y P*(y | x_k) R(x_{k−1} | z, y)
             = Σ_y [ Σ_{x_k} P*(z, x_k) P*(y | z, x_k) ] R(x_{k−1} | z, y)      （定理 3.1：P*(y | x_k) = P*(y | z, x_k)）
             = Σ_y P*(z, y) R(x_{k−1} | z, y)
             = P*(z, x_{k−1})                                                    （引理 2.1）
```

∎

**a_T = 0 时，B 就是现有的 renoise 采样器**：R(x_{k−1} | z, y) = K_{a_{k−1}}(x_{k−1} | y)。所以 renoise 在独立配对下精确的论证（DDIM 式）是命题 5.2 的特例。

**网络只给逐位边缘时（重要，复核后改正）。** 网络输出 p̂_i ≈ P*(y_i = 1 | x_k)，用它代替 Ŵ 就是把联合后验换成各位独立的乘积。单步上两种采样器都只丢了各位之间的相关性：

- A：给定 x_k，x_{k−1} 的每一位的边缘是精确的；
- B：给定 (z, x_k)，同样只有每一位的边缘是精确的。

但两者的累积误差性质不同：

- **A 的误差随步数 N 增大而趋于 0。** 相邻两步的 x_{k−1} 与 x_k 只差 O(1/N) 个位，单步丢掉的相关性来自“两位在同一步一起翻转”，概率是 O(1/N²) 级，累积 O(1/N)（这是启发式论证；Di4C，Hayakawa 等 2025，§2.2 对这类采样器给出 O(1/N) 的结论）。数值上见下表。
- **B 的误差不随 N 趋于 0。** B 每一步都以 z 为端点、按乘积型的 ŷ 重新抽一遍 x_{k−1}，x_{k−1} 与 x_k 之间不必接近，于是每一步都重新引入一次 O(1) 的相关性误差，步数再多也平均不掉。命题 5.2 的精确性依赖联合后验，不能延伸到乘积型网络。

精确枚举的结果（n = 7，4 个标签，a_T = 0.3，精确的逐位后验，线性信号表；测试 `test_product_denoiser_samplers`）给出终点分布与 π1 的总变差：

| 步数 N | 4 | 16 | 64 |
|---|---|---|---|
| A | 0.188 | 0.026 | 0.0045 |
| B | 0.218 | 0.040 | 0.027 |

对抗复核在 n = 6 上独立算到 N = 1024：A 一直按 1/N 下降（a_T = 0.4 时 N = 1024 为 0.0003），B 停在约 0.02（a_T = 0.4）和 0.026（a_T = 0）。

**这对现有实验的含义。** a_T = 0 时 B 就是现有的 renoise 采样器（`experiments/20261119_difusco_rbsmall_reach/launch.sh` 用的就是它），所以现有 DIFUSCO 基线本身就带着这个不随步数消失的偏差，这与 SB 无关。路线 1 的实验因此应当两种采样器都评测（plan.md 1C 已列出 A、B 两种）；SB 配对的好处（同一 z 走近邻标签）在 B 下只是近似成立。

## 6. 独立配对的极限

**命题 6.1 [推导]。** a_T = 0 时：

- K_{a_T} 是常数，π*(m | z) = g_m / Σ g，所以 Sinkhorn 的解是 g ∝ π1，配对是独立配对 π0 ⊗ π1；
- 定理 3.1 的后验退化为 w_m ∝ π1(m) K_{a_k}(x_k | s_m)。π1 均匀时，这就是现有软目标 `label_sets.posterior_mean`。

**SB 用的信号表。** 由现有 DIFUSCO 余弦表的信号 ã_k（= Q_bar[k] 的 [0,0] 元减 [0,1] 元）构造：

```
a_k = a_T + (1 − a_T) · ã_k   （1 ≤ k ≤ T），   a_0 = 1，   a_T 为给定参数
```

（代码 `sb_signal_schedule`。）

- 单调不增，a_0 = 1，每一项都 ≥ 参数 a_T（代码里有断言）。
- 现有余弦表在 k = T 不精确为 0：ã_T 约为 9.71 × 10^{−7}（T = 50），2.4 × 10^{−7}（T = 100），2.4 × 10^{−9}（T = 1000）。所以噪声端实际用的信号是 a[T] = a_T + (1 − a_T) ã_T，比参数 a_T 略大。Sinkhorn、桥、ω 一律用这个 a[T]，整套推导对它严格成立。
- a_T = 0 时每个下标（包括 k = T）都与现有表完全相同。测试 `test_independent_limit_matches_difusco_soft_targets` 用 Sinkhorn 的输出（而不是直接取 g 为常数），在每个下标抽 64 个 x_k，与现有软目标的差 < 1e-6（g 由 4096 个蒙特卡洛起点求出，在 a[T] ≈ 1e-6 下与常数只差蒙特卡洛噪声）；同时检查 a_T = 0.1、0.01、0.001 时 SB 目标与独立目标的差单调趋于 0。

## 7. 蒙特卡洛 Sinkhorn

真实图有 n ≈ 220–300，不能枚举 2^n 个起点。做法：抽 K 个起点 z_1..z_K ~ Bernoulli(0.5)^n，在经验分布上解 Sinkhorn。

**对偶形式 [推导]。** 噪声端的势 f 可以消掉（§2 末），Sinkhorn 只剩 M 维的 h = log g。它是下面这个凹函数的坐标上升（不动点就是最大值点）：

```
Φ(h)   = Σ_m π1(m) h_m − E_{z~π0} [ logsumexp_m( h_m + log K_{a_T}(s_m | z) ) ]
Φ_K(h) = Σ_m π1(m) h_m − (1/K) Σ_j logsumexp_m( h_m + log K_{a_T}(s_m | z_j) )
```

∇Φ(h) = π1 − (配对在 h 下的标签边缘)，Hessian 是 −E_z Cov_{π*(·|z)}，它的零空间恰好是常数向量（对应 h 加常数），所以 h 在相差常数的意义下唯一。

**误差 [标准，M 估计量的渐近理论]。** h_K = argmax Φ_K 是一个 Z 估计量（∇Φ_K(h) = 0 的解）。在固定 n、M 下，K → ∞ 时 h_K → h*，误差约为

```
h_K − h* ≈ H^{-1} · (∇Φ_K − ∇Φ)(h*)，   H = E_z Cov_{π*(·|z)}（限制在与常数正交的子空间上）
```

右边括号里是 K 个独立的 M 维有界向量的均值，量级 sqrt(M/K)。所以误差约为 ‖H^{-1}‖ · sqrt(M/K)。

- 这个论证只涉及 M 维，不涉及 2^n 个状态，所以对 n ≈ 250 有意义。（"经验分布收敛到 π0"的原始论证要 K ≫ 2^n 才起作用。）
- ω 大时 π*(·|z) 接近 one-hot，H 退化，需要的 K 变大；M 大时也要更大的 K。

**真实图上的量级（对抗复核测得，`runs/scratch/m1_review/check_mc_real.py`，KaMIS 多解 `matched_kamis_loaderorder.pt`，n = 220，M = 115）。**

- K = 65536 时，用 2^20 个新起点测得的标签边缘最大相对误差：ω = 0.35 为 2.7%，ω = 1.0 为 6.4%。
- 每次求解 6–120 次迭代，在样本上的边缘误差约 1e-12，0.1–0.3 秒（GPU）。
- 结论：阶段 1A 的 "< 2%" 在 M 大、ω ≥ 1 时需要 K 到 10^6 量级。1A 要按 ω 报告所需的 K，并且测量用的新起点数 K_test 要远大于 K（测量本身有约 sqrt(M/K_test) 的相对噪声，M = 115、K_test = 2^20 时约 1%）。

**g 不精确时其余推导仍自洽 [推导]。** 定理 3.1、推论 3.2/3.3、命题 5.1/5.2 对任何正的 g 都成立：只要把配对定义为 π_g(z, m) = π0(z) · softmax_m(log g_m + log K_{a_T}(s_m | z))，它就是参考过程的 h 变换（f(z) = π0(z) / Σ_m g_m K），训练目标、训练样本的抽法与两种采样器都对这个 π_g 精确。蒙特卡洛误差只让终点的标签边缘偏离 π1，不会让训练和采样互相矛盾。

**小例子。** 测试 `test_monte_carlo_sinkhorn_converges`（n = 10，可精确枚举）显示：K = 256、4096、65536 时，标签边缘的误差单调下降，最后一档 < 5 × 10^{−3}。它只验证实现，不代表真实图的量级。

## 8. SB 配对与独立配对的比较

**命题 8.1 [推导]。** 0 < a_T < 1（a_T = 1 时两边的 KL 都是 +∞），M ≥ 2 且标签两两不同时，KL(π* ‖ R_{0T}) < KL(π0 ⊗ π1 ‖ R_{0T})。

证明：独立配对可行，所以 ≤ 成立。若等号成立，由唯一性，独立配对就是 π*，于是它具有定理 2.2 的形式，即 π1(m) / (g_m K_{a_T}(s_m | z)) 只依赖 z。

取 s_1 ≠ s_2。比较 m = 1, 2 得出 K_{a_T}(s_1 | z) / K_{a_T}(s_2 | z) 与 z 无关。但这个比值等于

```
exp( −ω (|s_1| − |s_2|) + 2ω (|z ∧ s_1| − |z ∧ s_2|) )
```

取一位 i 使 s_1,i ≠ s_2,i，翻转 z 的第 i 位会让 |z ∧ s_1| − |z ∧ s_2| 改变 ±1，在 ω > 0 时比值随之改变，矛盾。∎

**数值。** 精确小例子里两者的 KL 都已报告，SB 的 KL 均低于独立配对；ω → 0 时两者的差趋于 0（`runs/scratch/sb_plan_1125/check_static_sb.py`）。

### 12.1 CSBM（Ksenofontov & Korotin 2025，arXiv 2502.01416）

- **设定**：有限类别空间 S^D，离散时间 0 = t_0 < ... < t_{N+1} = 1，只做离散时间。
- **参考过程**：每维一条独立的马尔可夫链。均匀参考（式 7）的转移是：留在原类别的概率 1 − α，换到每个其他类别的概率 α/(S − 1)。
  - S = 2 时就是我们的逐位对称翻转（§1）。每步保留信号 1 − 2α，对应我们的 a_k / a_{k−1}。
- **D-IMF（式 5、6）**：交替做两种投影，初值可以是任意配对。
  - 互易投影：用参考桥把配对 q(x0, x1) 补成路径。
  - 马尔可夫投影：取路径相邻两时刻的条件分布，组成马尔可夫链。它保持所有时间边缘不变，但会改变两端的配对。
- **收敛**（定理 3.1、推论 3.2，第 309–337 行）。条件是：
  - p0、p1 在 X 上全支撑；
  - 参考过程在 X^{N+2} 上全支撑；
  - 投影精确。
  
  结论是 KL(q^l ‖ q*) → 0。论文没有给收敛速率，也没有分析近似误差。
  - 我们的 π1 只支撑在标签上，不满足"全支撑"这一字面条件。DDSBM 的定理 3.3 不要求全支撑，只要求初值与 SB 的 KL 有限，独立配对满足这一条；但那是连续时间的定理。本节 12.3 用精确计算直接验证了我们的情形。
- **参数化**（式 9）：网络预测终点 x1，转移等于"对预测的 x1 求期望的参考桥转移"，逐维分解。所有时间步共用一个带时间输入的网络。后向网络对称地预测 x0。
- **损失**（命题 3.3，式 10、21、22）：逐步 KL 加 0.001 倍的交叉熵。与 D3PM 唯一的不同是中间状态从参考**桥**采样。附录 C.1 指出任何 Bregman 散度都有相同的最小点。
- **训练**（算法 1）：严格交替。
  - 前向网络在"真实 x1 + 后向模型生成的 x0"上训练；
  - 后向网络在"真实 x0 + 前向模型生成的 x1"上训练。
  - 理由（第 427–437 行）：单向训练会给 IMF 带来误差（引 De Bortoli 等 2024 附录 I）。
- **实验设置**（表 5，第 1207–1233 行）：
  - 外层迭代 3–10 次；第一次 20 万–80 万梯度步，之后每次 4 万步；
  - 初始配对为独立配对或小批量 OT；
  - AdamW，EMA 0.999（MNIST 用 0.9999）。
  - 论文没有说明配对是否用 EMA 模型生成、每轮是否接着上一轮的参数训练。

### 12.2 DDSBM（Kim 等 2025，arXiv 2410.01500）

- **参考过程**：连续时间，节点和边各自独立变化，转移为 P_{s:t}(x, y) = (ᾱ(t)/ᾱ(s)) δ_xy + (1 − ᾱ(t)/ᾱ(s)) m(y)。
  - 二类、m 均匀时，"不同"与"相同"的代价差是 log((1 + α)/(1 − α))（附录 D.6），与我们的 ω 完全一致。
- **收敛**（定理 3.3）：KL 单调不增，依分布收敛到 SB。
- **算法**（附录 C 算法 1）：前后向交替，初始配对随机，每轮重新生成训练配对，外层 2–10 轮。论文没有提到 EMA，也没有提到配对缓存。
- **同时训练**：两篇论文都没有"在同一批样本上同时训练两个方向"的做法。最接近的是 DSBM（arXiv 2303.16852）附录 G 的联合训练：新配对取前后向两个模型的 ½ 混合，另加一个基于 SDE 时间反转的一致性损失。这个损失在离散空间没有直接的对应。

### 12.3 精确的表格 D-IMF 在我们的设定上收敛（1D 验收标准 1）

`cam/utils/sb_imf.py` 在全部 2^n 个状态上精确执行 D-IMF，不用网络，float64。

- **投影的写法**：互易投影用 §4 的逐位桥。相邻时刻的联合分布为

  J_k(x_{k−1}, x_k) = R_k(x_{k−1}, x_k) · Σ_m K_{a_{k−1}}(x_{k−1} | y_m) · G_k(x_k, m)，

  其中 G_k(x, m) = Σ_z K_{a_T/a_k}(z | x) q(z, m) / K_{a_T}(z | y_m)，R_k = K_{a_k/a_{k−1}}。
  - 推导：路径律等于 q(z, m) 乘以参考桥。参考桥 = K_{a_{k−1}}(x_{k−1} | y) R_k(x_{k−1}, x_k) K_{a_T/a_k}(z | x_k) / K_{a_T}(z | y)，由参考过程的马尔可夫性得到。
- **两个方向的马尔可夫投影**：
  - 采样方向：取 P(x_{k−1} | x_k)，从 π0 出发连乘到标签；
  - 加噪方向：取 P(x_k | x_{k−1})，从 π1 出发连乘到 z。
  
  两个方向交替。
- **测试**：`cam/tests/test_sb_imf.py`，12 项全部通过。6 个实例：n = 5–8，标签 5–12 个，T = 2–8，ω = 0.35–3，其中 2 个用按大小加权的 π1。
  - **收敛**：每个实例都收敛到 Sinkhorn 解，TV < 1e-3。
    - ω ≤ 1 的 4 个实例，分别在 4、5、9、19 次投影后低于 1e-3；
    - ω = 2、3 两个实例分别要 43、70 次；
    - 2000 次投影后，所有实例的 TV ≤ 3e-13。
  - **单调性与边缘**：到 SB 的 KL 单调不增；每次投影后两端边缘误差 < 1e-12。
  - **不动点**：SB 解是两个方向投影的不动点，误差 < 1e-10。
  - **单向迭代**：投影精确时，只做采样方向的投影也收敛。双向交替只在投影有近似误差时才有必要，与文献一致。
  - **反向对照**：
    - 用前向边缘代替桥（忽略 z）：TV 停在 0.02 以上；
    - 与另一个 ω 的 Sinkhorn 解比较：差距 > 1e-2。
- **对 1D 的含义**：在我们关心的 ω ≤ 1，精确 D-IMF 十几轮内收敛。学出来的配对达不到闭式配对时，原因是网络的近似误差，不是迭代本身慢。

### 12.4 1D 的做法（据 12.1–12.3 定）

- **前向网络**：就是现有的 SB 版 DIFUSCO（预测标签后验的均值，按桥重加噪，§5）。
- **后向网络**：预测起点 x0（逐位），结构同前向网络，不做"标签混合"一类的新结构。
- **同时训练**按 plan.md 的要求做，采用"交叉喂入"：
  - 同一次参数更新里，前向网络的配对由后向网络从真实标签生成（x1 ~ π1 是真的）；
  - 后向网络的配对由前向网络从真实起点生成（x0 ~ π0 是真的）。
  
  在投影精确、每轮固定快照的理想情况下，这等价于两条合法的交替 D-IMF 链，保留了交替的去偏作用。这一点是我们的推断，文献里没有。
- **初始配对**：独立配对。第一轮就是 1B 的独立配对基线，可以直接从它的 checkpoint 开始。
