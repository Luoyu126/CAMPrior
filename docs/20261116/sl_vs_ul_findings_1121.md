# 监督学习为什么不如无监督：发现汇总与固定流程（11-21）

任务：RB-small 上的 MIS。监督学习（SL）指 DIFUSCO（用求解器的解作标签训练），无监督学习（UL）指 DiffUCO（用能量训练）。
测试设置不变：1000 张测试图，50 个去噪步，每图 20 个样本，贪心解码，取最大，报平均大小。
DiffUCO 在这个设置下为 **19.880**（测试种子 0–3）。

结论：SL 落后于 UL 有两个来源，**训推不一致**和**标签的好学程度**。两者分别处理后，SL 在 renoise 采样下与 DiffUCO 相近。

> **11-24 作废说明：** 下文 A / B 两组（KaMIS 多解）的标签节点顺序错了（`docs/mis_rbsmall_label_sets.md` 第 5 节），涉及 A / B 的数字和结论都作废，包括“解码后再加噪在 KaMIS 上 +0.2”和“KaMIS 多解比单标签更难学”。C / D 两组不受影响。 修正后重跑：KaMIS 多解 renoise 19.836 / 19.823（随机抽 / 软目标），比 DiffUCO 多解低 0.04–0.06（后验下低 0.11–0.16）；解码后加噪在 KaMIS 上只 +0.03。

## 1. 训推不一致

### 1.1 采样：renoise（主要提升；方法来自已有工作）

两种采样器都是"每步由网络得到 x̂₀，再加噪回 t−1"，区别只在加噪这一步：

- D3PM 后验（DIFUSCO 原文）：x_{t−1} ~ q(x_{t−1} | x_t, x̂₀)，会保留当前 x_t 的大部分节点。
- renoise：先按 p 抽一个完整解 x̂₀，再用训练时的前向 q(x_{t−1} | x̂₀) 逐节点翻转。网络每一步的输入都是"一个解加上训练时的那种噪声"，和训练输入同一形式。

renoise 与 Fast T2T 的多步一致性采样完全相同：arXiv 2502.02941 第 5.1 节算法 1；官方代码
`ref/Fast-T2T/diffusion/consistency/mis.py` 第 123–131 行已核对。在分布上它也等于 DDIM 离散版取 σ_t = 0
（arXiv 2010.02502 附录 A 式 20）。**这不是我们的贡献**，论文中应写作沿用。
两者耗时相近：每图 0.62 秒对 0.61 秒，DiffUCO 0.54 秒。

同一模型、两种采样器（2×2 标签实验，训练种子 × 测试种子各 2 个的平均）：

| 模型 | D3PM 后验 | renoise | 差 |
|---|---|---|---|
| A KaMIS 多解 + 随机抽一个 | 19.242 | 19.536 | +0.29 |
| B KaMIS 多解 + 软标签 | 19.275 | 19.581 | +0.31 |
| C DiffUCO 多解 + 随机抽一个 | 19.616 | 19.871 | +0.26 |
| D DiffUCO 多解 + 软标签 | 19.656 | 19.884 | +0.23 |

单个样本也更好，不只是取最大的结果更好。D 组、种子 0 的 20 个样本平均大小：后验 18.51，renoise 19.04。

**机制尚未坐实。** 我们记录了采样轨迹上网络输入的统计量（`CAM_TRACE_INPUTS`，
`runs/scratch/sampler_1121/trace_*.jsonl`），并和"本条链的最终解按训练前向加噪到同一 t"的输入比较：
- 选中节点数：两种采样器都与训练形式一致。
- 相邻两点同时为 1 的边数：后验在最后几步多出约 60%（t = 1 时 0.81 对 0.51），renoise 多出约 37%（0.71 对 0.52）。
- 预测与最终解的交叉熵：后验在轨迹中段更低，说明它更早定下解，之后很少再改。

所以"后验的输入明显偏离训练分布"在这些一阶统计上并不明显。目前更符合数据的说法是：后验保留 x_t，早期的错误难以纠正；
renoise 每步重新决定，纠错更快（与 Restart Sampling 的"随机性收缩累积误差"一致，arXiv 2306.14878 定理 1）。
"训推一致"的解释还需要更直接的度量。

### 1.2 新做法：解码后再加噪（renoise_decode；有待验证）

每步抽出 x̂₀ 后，先用问题自带的贪心解码把它变成合法、且不能再加点的解（抽中的节点优先，按 p 排序），再加噪回 t−1。
这样网络输入是"合法解加训练噪声"，训练时的标签也都是合法的最大解。这一步只用解码器（任何 CO 问题都需要），不用能量函数。
对照 `renoise_feasible` 只去掉冲突的节点、不补节点。
开关：`--difusco_sampler renoise_decode | renoise_feasible`，见 `cam/solvers/difusco.py` 的 `decode_x0` 和 UPSTREAM.md 第 59 条。

结果（1000 张测试图，每组 2 个训练种子 × 2 个测试种子；逐图配对，95% 区间）：

| 组 | renoise | 解码后加噪 | 差 | 只去冲突 |
|---|---|---|---|---|
| A KaMIS + 随机抽一个 | 19.536 | 19.772 | +0.236 [+0.217, +0.256] | — |
| B KaMIS + 软标签 | 19.581 | 19.783 | +0.203 [+0.184, +0.221] | 19.504 |
| C DiffUCO + 随机抽一个 | 19.871 | 19.876 | +0.005 [−0.007, +0.016] | — |
| D DiffUCO + 软标签 | 19.884 | 19.891 | +0.007 [−0.005, +0.019] | 19.857 |

- 难学的 KaMIS 标签上提升约 0.2，但仍远低于 DiffUCO 标签。好学的 DiffUCO 标签上几乎没有提升（区间含 0）。
  它主要是在补救"学不会的标签"。
- 只去冲突、不补节点反而更差。

**同等时间下不划算**（前 200 张测试图，D 组训练种子 0，单独占一张卡，`runs/scratch/sampler_1121/timing*`）：

| 采样 | 每图样本数 | 每图耗时 | 结果 |
|---|---|---|---|
| D3PM 后验 | 20 | 0.38–0.40 秒 | 19.725 |
| renoise | 20 | 0.39–0.40 秒 | 19.855 |
| renoise | 40 | 0.41 秒 | 19.955 |
| renoise | 100 | 0.62 秒 | 20.035 |
| 解码后加噪 | 20 | 0.79–0.81 秒 | 19.905–19.910 |
| 解码后加噪 | 40 | 0.80 秒 | 19.980 |

每步多一次 Python 循环的贪心解码，耗时约为 renoise 的 2 倍。renoise 多采样本几乎不加时间，同等时间下更好。
**结论（11-21 定）：默认采样用普通 renoise；解码后加噪记为可选附件**（`--difusco_sampler renoise_decode`）。在 MIS 的好学标签上它不划算，
但在可行性约束更强的问题（如 TSP，回路约束）上可能变得关键，扩展时要重新测。它也是"难学标签上，训推不一致代价更大"的证据。
（第 1.1 节"0.61 / 0.62 秒"是两个测试共用一张卡时测的，单独测约 0.4 秒。）

新意检查（已读原文）：
- Fast T2T 的 rewrite（`pl_mis_model.py` 第 225 行起）和 GenSCO（NeurIPS 2025 第 4 节，算法 1）都在外层搜索循环中解码，再加噪或扰动。
  GenSCO 的扰动是针对 MIS 设计的翻转，并且用目标值作反馈。
- Projected Diffusion Models（arXiv 2402.03559）在连续扩散中每步把带噪状态投影到约束集。
- 都不是"标准扩散轨迹中，每步把预测的 x̂₀ 解码成合法解再按训练前向加噪"。还需要系统检索后才能声称是新做法。

### 1.3 训练扩散步数与推理对齐（调参性质，如实记录）

用 50 个扩散步训练，推理的 50 步恰好走遍训练时的 50 个时刻（Fast T2T 式 4 的做法），代替原来的 1000 步训练：

| 标签 | 1000 步训练 | 50 步训练 |
|---|---|---|
| DiffUCO 200 个样本取最大（renoise） | 19.758 | 19.828（3 个训练种子） |
| KaMIS 单标签（renoise） | 19.669 | 19.761（2 个训练种子） |

提升约 0.07–0.09（后验下约 0.01–0.03）。这一步主要是让训练与推理的时间步一致，我们认为属于调参，不作为方法贡献。

## 2. 标签的好学程度

### 2.1 现象：标签更小，训出的模型却更好

KaMIS / DiffUCO × 随机抽一个 / 软标签：每图两种来源的标签个数对齐为 42 个；50 步训练，400 个 epoch，2 个训练种子。

| 组 | 标签平均大小 | renoise | D3PM 后验 |
|---|---|---|---|
| A KaMIS + 随机抽一个 | 20.162 | 19.536 | 19.242 |
| B KaMIS + 软标签 | 20.162 | 19.581 | 19.275 |
| C DiffUCO + 随机抽一个 | 20.124 | 19.871 | 19.616 |
| D DiffUCO + 软标签 | 20.124 | 19.884 | 19.656 |

逐图配对，图级 bootstrap 95% 区间（`experiments/20261119_difusco_rbsmall_reach/paired_arms.py`）：

- C − A = +0.336 [+0.313, +0.359]（后验下 +0.374）；D − B = +0.303 [+0.282, +0.325]（后验下 +0.381）。
- DiffUCO 标签小 0.04，模型却高约 0.3；两种来源的多样性相近（解与解平均相差 19 个节点）。

好学程度可以量化。在训练图上，"标签大小与模型能达到的大小之差"，与"这个大小在 DiffUCO 样本中有多常见"的秩相关为 0.70，
与单步去噪损失只有 0.18。诊断显示瓶颈是"学不会"，不是标签上限：标签上限比 DiffUCO 自己的结果高 0.2。
详见 `docs/20261116/difusco_sota_soft_labels.md` 第 4 节。

一个需要解释的现象：KaMIS 的多个最大解（换随机种子得到）反而比单个 KaMIS 标签更难学。
同为 50 步训练，单标签 19.761，A 组多标签 19.536。DiffUCO 则相反，多标签有帮助。
可能是 KaMIS 不同种子的解之间缺乏一致的"风格"，模型只能学到它们的平均。这一点还没拆开验证（两者 epoch 数也不同）。

### 2.2 软标签：把 Stable Target Field 用到离散标签集上

目标是整组标签在当前加噪状态下的后验均值：

y_i = Σ_m w_m s^m_i，其中 w_m = softmax_m(−λ_t · d_H(s^m, x_t))，λ_t = log((1+ᾱ_t)/(1−ᾱ_t))。

最优解与"随机抽一个"相同，但目标的方差更小（Rao–Blackwell）。思路来自 Stable Target Field（arXiv 2302.00670）：
那里在连续空间用一批参考样本近似加权平均；这里是离散的二元对称噪声，每图的标签集有限，可以精确计算。

提升（逐图配对，95% 区间）：
- B − A = +0.045 [+0.028, +0.062]，D − C = +0.013 [+0.001, +0.024]（renoise）。
- 后验下分别为 +0.033、+0.040。
- 两个训练种子方向都一致；标签越难学（KaMIS），提升越大。

renoise 下与 DiffUCO 相近或略高（800 epoch、3000 样本时配对差 +0.034 [+0.020, +0.048]，只有 2 个训练种子）。

## 4. 固定流程（SOP）

1. **标签**：在训练图上，用一个"好学"的求解器（目前是训练好的 DiffUCO）按它自己的测试协议采样，每图 1000 个样本。
   保留其中所有不同的最大解（`cam/scripts/mis/ul_samples.py` → `cam/scripts/mis/diverse_labels.py`）。
   换求解器时，先用好学指标打分（`experiments/20261119_difusco_rbsmall_reach/ceiling_vs_learnability.py`）。
2. **训练**：DIFUSCO GNN（8 层，宽 64），50 个扩散步，余弦噪声表，`--label_choice soft`。
   AdamW，学习率 2e-4，权重衰减 1e-4，余弦衰减；每步 40 张图，400 个 epoch。
   每个 epoch 在 64 张验证图上用 renoise 测一次，保留最好的 checkpoint。
   启动：`bash experiments/20261119_difusco_rbsmall_reach/launch.sh <gpu> <模式>_long_soft <seed>`。
3. **推理**：50 步，逐个走遍训练的 50 个时刻，`--difusco_sampler renoise`（解码后加噪同等时间下不划算，不用）。
   每图 20 个样本，贪心解码，取最大。
4. **报告**：renoise 为主，同时报 D3PM 后验；用逐图配对比较；每个设置 4 个训练种子即可下结论，接近时报"相近"。

## 5. 局限与待办

- 标签来自 DiffUCO，即依赖一个已训练好的 UL 模型。扩展到新问题时，要么先训 UL，要么找别的好学标签来源。这是扩展前要回答的问题。
- 2×2 实验每组只有 2 个训练种子。
- 与其他方法对比需统一样本数：增加样本几乎不加时间，应在 1000 张图、4 个训练种子上用 100 个样本重测，DiffUCO 同样。
- renoise 优于后验的机制：需要比一阶统计更直接的"训推不一致"度量。
- KaMIS 多解为何比单解更难学，未拆开验证。

## 6. 下一步：扩展

按问题类型和规模扩展，沿用上面的固定流程：
- 规模：RB-large（RB-[800-1200]），ER-[700-800]。大图上 DiffUCO 与 KaMIS 的差距更大，标签上限可能重新成为问题。
- 问题类型：MaxCut、MaxClique、MDS（DiffUCO 原文 arXiv 2406.01661 表 1、表 3：MIS 用 RB-small / RB-large，MaxCl 用 RB-small，MDS、MaxCut 用 BA-small / BA-large）。另外可用不同分布的 MIS（SATLIB）检验泛化。
