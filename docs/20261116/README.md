# 2026-11-16：新主线的想法——把能量先验放进有监督扩散的前向过程

和 Shengyu 讨论（11-14/15）之后的新方向。之前的 CAMPrior（11-14 快照见 `docs/20261114/README.md`）不再是主线。

## 1. 为什么换方向

CAMPrior 做的事是：把一个好的先验（RLSA）当作参考，训练出来的网络比 CAM 好一些。

这件事本身不太出人意料，对社群帮助有限。更重要的是，它没有在回答一个问题，所以没有明确的 takeaway。

## 2. 新的问题

**观察**：在最大独立集（MIS）上，现在无监督方法（UL，用能量函数训练，不需要标签）的结果普遍好于有监督方法（SL，模仿求解器给出的最优解）。

**问题**：原因是什么？

**一个假设**：
- UL 方法从噪声走到一个好的分布，过程中直接用到能量函数。例如 RLSA、CAM 每一步都用能量对 x 的（离散）梯度来决定往哪走，所以路径更“直”。
- SL 扩散方法（以 DIFUSCO 为代表）从标签出发，不断加和问题无关的噪声，直到变成一个平滑的分布，再让网络学反过来的过程。
- 这样 SL 没有用上 MIS 最好的一个性质：它是 QUBO 类问题，有形式很好的能量函数。

**如果这个假设成立**，就可以把先验放进 SL，看能否追平 UL。

一个具体做法，以 DIFUSCO 为例：
- 前向过程不用传统的加噪，而是**反着跑 RLSA**：利用能量，让前向过程沿着能量升高的方向，从标签走到高能量/无序的状态。
- 再让网络学这个前向过程的反向过程。

## 3. 要先验证的三个前提

1. 在 MIS 上，UL 是否普遍好于 SL？
2. SL 的现有方法，是否都是“从标签出发、不断加噪声变成平滑分布、再学反向”？
3. 用能量（比如反向 RLSA）来定义前向过程、再学反向，有没有人做过？
