# CAMPrior 进展快照（截至 2026-11-14）

这份文档在和 Shengyu（CAM 作者）讨论、重新确定主线之前，记录到 11-14 为止的方法、贡献和实验结果。结构跟进展汇报的幻灯片（"CAMPrior 进展"，12 页）一致；更细的实验记录在 `docs/status.md`，标签理论分析在 `docs/label_correction.md`。

## 1. 方法：把 RLSA 同时放进 CAM 的策略和参考过程

状态 x ∈ {0,1}^N，X_0 ~ 均匀分布，第 k = 0,…,K−1 步每个坐标以 p_i 独立翻转。H 是带罚项的能量（MIS：−Σx_i + β Σ_(i,j)∈E x_i x_j）。

- **模块 A：先验进策略。** p_i(x, k) = σ(a_i(x, k) + r_i(x; θ))。a_i = (δ_i − δ_(d)) / τ_p 是 RLSA 的翻转 logit，δ_i = ½ ∂_i H(x)·(2x_i − 1) 是翻转 i 带来的一阶能量下降的一半，δ_(d) 是第 d 大的 δ（RLSA 的 top-d 阈值），τ_p 是先验温度（采样步内按 RLSA 线性退火，训练中随 CAM 的训练温度缩放）。网络只学残差 r。
- **模块 B：先验进参考过程。** 损失 L(θ) = Σ_i [ −p_i·T_i + τ·KL(Ber(p_i) ‖ Ber(σ(a_i))) ]，KL 的锚点从均匀翻转换成 RLSA。最优解是 σ(a + T/τ)，保留先验。
- **关键简化：标签直接沿用。** T_i = exp(−(1−w))·∂_i H(X_1)·(2x_i − 1) 是 CAM 原来的标签。它是在"参考过程与状态无关"（离散版布朗运动）下推出的；参考换成依赖状态的 RLSA 后仍沿用，相当于忽略了连续 adjoint 方程里的 ∇f 项。不反向求解，开销和 CAM 相同。

模块 A、B 都可以单独关掉（`--prior_policy off`、`--prior_kl_ref uniform`），用来做拆解实验。代码：`cam/solvers/cam_prior.py`。

## 2. 相关工作

| 工作 | 场景 | 策略里的先验（A） | 参考过程 / KL 锚点（B） | adjoint 标签 |
|---|---|---|---|---|
| NAAS（Choi 等，2025） | 连续 · 无偏采样 | 退火 Langevin 漂移 + 残差 | 退火 Langevin | 精确：反向解 lean adjoint ODE（含 Hessian 项） |
| DASBS（Guo 等，2026） | 离散 · 无偏采样 | 无 | 均匀翻转；非均匀参考列为未来工作 | 均匀参考下精确 |
| CAM（Feng 等，2026） | 离散 · 组合优化 | 无 | 均匀翻转 | 均匀参考下精确 |
| RLSA / RLNN（Feng & Yang，2025） | 离散 · 组合优化 | RLSA 本身是免训练采样器；RLNN 用网络拟合转移 | — | — |
| NLD4CO（Ma 等，2026） | 离散 · 组合优化 | 网络只给 Langevin 一个热启动初值 | — | — |
| **CAMPrior（我们）** | 离散 · 组合优化 | RLSA logit + 残差 | RLSA | 沿用均匀参考下的标签，不反向求解 |

在强化学习里最像的做法是 Residual Q-Learning、Residual Policy Gradient（在先验策略上学残差，KL 正则到先验策略），论文里要引。PDF 在 `ref/lit_pdfs/`。

## 3. Contribution

1. **解质量。** 在 MIS、MaxCut 的无监督学习求解器（CAM 论文表 1、RLSA 论文表 1 的 UL 组：DIMES、DiffUCO、SDDS、RLNN、CAM）中，CAMPrior 达到最好的解质量，而且只训了 CAM 论文 1/10 的 epoch。
   - 注意：和 CAM 论文的差距只有 0.02–0.09，在种子波动之内；要说 SOTA，需要 3 个种子按 validation 挑的最好 checkpoint 的平均。不和 OR 求解器（KaMIS）、免训练搜索（RLSA 大预算、pCQO）比。
2. **标签直接沿用就够了。** 在离散组合优化上，把参考过程换成依赖状态的 RLSA 后，直接沿用均匀参考下的 adjoint 标签（不反向求解，开销同 CAM），训练就是稳定的。ER-[700-800] 3 个种子收敛后（第 20–100 个 epoch）test 的标准差 0.13 / 0.26 / 0.16，CAM 是 2.11 / 0.95 / 1.04；RB、MaxCut 上也没有发散。
   - 反面证据：更"精确"的一阶标签（NAAS 式 22 的离散版）在 RLSA 参考下发散；模拟标签（按 DAM 式 12，从两个候选状态各跑一条 RLSA 到终点取差）停在约 40。所以这里的结论是"这个近似够用而且好训"，不是"这样构造是精确的"。
3. **A 和 B 各自的作用。** A 决定起点：先验进策略，训练前就是 RLSA，1 个 epoch 到 43。B 决定收敛到哪：最优解 σ(a + T/τ) 保留先验。两者一起才稳：收敛后 test 标准差，单独 A 1.16、单独 B 3.82，A + B 0.13。

## 4. 实验结果

### 4.1 MIS：CAMPrior vs CAM

都是 test（或迁移）分数，50 步 × 20 条链（大图迁移 200 步 × 20 条链）。训练 100 个 epoch（RB-large 150 个），是 CAM 论文的 1/10。

| 数据集 | 口径 | CAM（曲线最高） | CAMPrior（曲线最高） | 同预算 RLSA | CAM 论文（1000 epoch） | KaMIS |
|---|---|---|---|---|---|---|
| ER-[700-800] | 128 张图，3 个种子平均 | 43.05 | **44.18** | 39.94 | 44.16 | 44.87 |
| ER-[9000-11000]（用 ER-[700-800] 的模型迁移） | 16 张图，3 个种子平均 | 380.5 | **388.0** | 339.69 | 384.38 | 381.31 |
| RB-[200-300] | 1000 张图，种子 0 | 19.73 | **19.93** | 18.69 | 19.91 | 20.10 |
| RB-[800-1200] | 1000 张图，种子 0 | 40.99 | **41.33** | 35.50 | 41.25 | 43.15 |

按 validation 挑的 best.pt（种子 0）：ER 44.18 对 44.04，大图 383.3 对 379.3，RB-small 19.93 对 19.78，RB-large 41.34 对 41.07。读法：CAMPrior 的收敛速度和最优效果都优于 CAM。

### 4.2 MaxCut BA-[800-1200]（种子 0，1000 张 test 图）

- 第 1 个 epoch：CAMPrior 2961.3，CAM 2949.5；第 5 个 epoch：2963.1 对 2953.5。
- 收敛后（第 20–100 个 epoch）：CAM 2964.30 ± 0.42，CAMPrior 2963.90 ± 0.87。
- best.pt：CAMPrior 2965.65，CAM 2964.89（逐图配对差 +0.76，标准误 0.09）；CAM 论文 2964.20；同预算 RLSA 2914.9。
- 读法：MaxCut 上的优势是收敛快，最优效果和 CAM 接近，收敛后并不比 CAM 更稳。

### 4.3 解的多样性（ER-[700-800] test 前 32 张图，种子 1 第 90 个 epoch 的模型）

三种方法用同一组随机初始状态和每步同一组随机数（common random numbers），差别只来自翻转概率。

| | RLSA | CAM | CAMPrior |
|---|---|---|---|
| 每张图 20 条链里不同解的个数（平均） | 20 | 2.8 | 13.6 |
| 最后一步两两链之间不同节点的比例 | 9.6% | 1.1% | 7.1% |
| 最好一条链（平均） | 38.69 | 42.56 | 43.91 |
| 链平均 | 35.40 | 42.00 | 42.28 |

- 逐图比最好一条链：CAMPrior 赢 26 张、平 4 张、输 2 张。
- 路径形状：CAM 和 CAMPrior 第 1 步都把随机初始状态（约 380 个点）几乎删空，再每步加 5–10 个点；RLSA 是逐步删。大部分收益在前 10 步。
- 代价：32 张图里有 3 张，CAMPrior 的多数链掉进同一个差的解（链平均 37.8 / 39.9 / 39.4），所以只用一两条链评测时 CAMPrior 的优势会缩小。
- 推理时间（RTX 2080 Ti，32 张图）：CAM 0.76 秒/图，CAMPrior 0.77–0.82 秒/图，先验几乎不增加开销。CAM 论文 128 张图 55 秒（约 0.43 秒/图，硬件不同）。
- 代码：`cam/scripts/mis/infer_paths.py`；交互页面 https://claude.ai/artifact/5Q1oTEYbHCpvf79MHYcN3r。

### 4.4 方法拆解（ER-[700-800]，种子 0）

收敛后 = 第 20–100 个 epoch 的 9 个 test 点。

| 设计 | 收敛后 test 均值 ± 标准差 | test 最高 |
|---|---|---|
| CAM（A、B 都不加） | 42.11 ± 2.11 | 43.68 |
| 去掉翻转策略里的先验（只有 B） | 41.52 ± 3.82 | 44.19 |
| 去掉参考过程里的先验（只有 A） | 42.81 ± 1.16 | 43.80 |
| 弱热启动（先把 RLSA 蒸馏进网络，之后按 CAM 训练） | 43.01 ± 0.63 | 43.83 |
| 强热启动（蒸馏权重 + KL 对 RLSA，策略里不加先验） | 42.25 ± 2.04 | 44.27 |
| **CAMPrior（A + B）** | **44.01 ± 0.13** | 44.20 |

读法：各组最高分都在 43.7–44.3，差别不在能不能到高分，而在能否稳定停在高分。强热启动有 4 个点掉回 RLSA 水平，说明先验要一直留在参数化里。

### 4.5 更深：平滑标签（ER-[700-800]，CAMPrior，`--label_mode dense --label_lambda λ`）

把标签里终点的梯度 ∇H(X_(T−1)) 换成之后各步梯度的指数加权平均（权重 (1−λ)λ^(j−t−1)，剩余权重给终点）。λ = 1 是 CAM 原标签，λ = 0 只用下一步的梯度（RLSA 的局部信号）。

- 第 10 个 epoch：CAMPrior 43.68，λ = 0.97 / 0.9 / 0.5 分别 44.24 / 44.21 / 44.12。
- λ = 0.9 和 0.97 从第 10 个 epoch 起每个点都不低于 CAMPrior 基线 3 个种子的最大值，第 20–80 个 epoch 平均高约 0.25；λ = 0.5 与基线持平。
- 只有种子 0；种子 1、2（λ = 0.9 / 0.97）在 sa 集群 2、3、4、6 号卡上训练中，11-15 最新 validation 43.8–44.4。
- 各 λ 的标签和真实价值差的相关都 ≤ 0.35，所以即使提升成立，更可能来自方差或有效步长，而不是标签变准了。

### 4.6 更深：为什么沿用 CAM 标签仍能稳定训练（`docs/label_correction.md`）

- 前提不再成立：RLSA 参考下翻 1 个点，1 步后约 5 个点不同，5 步后 20–45 个，终点 35–85 个，扰动会扩散。
- 假设：CAM 标签在 RLSA 参考下是一个有偏、但几乎没有噪声的信号，指向"终点上的局部改进"。训练稳定靠的是方差低；代价是不动点比软最优更贪心。
- 证据：
  - 标签和真实优势的相关 ≤ 0.35；
  - 无偏但噪声大的模拟标签（信噪比约 0.02）训练停在 39.8–40.1（RLSA 水平）；
  - 同样的抽样只换标签，模拟标签 2–10 个 epoch 内掉到 35.4–35.8；
  - 小图逐状态精确计算显示 CAM 类标签的不动点更贪心（同样解质量 KL 3–20，精确标签 0.1–0.5）。
- 失效的例子：最大团。终点上的局部改进方向和全局方向不一致，标签严重不对称（"不要加"约 +10，"保留"约 −0.5）。

### 4.7 更广：最小支配集（非 QUBO，能量是高阶多线性函数）

- BA-[200-300]（test 1000 张）：第 10–100 个 epoch 平均 CAM 28.146、CAMPrior（先验温度 0.1）28.061；同预算 RLSA 28.464，Gurobi 27.89。
- BA-[800-1200]（test 1000 张，评到第 70 个 epoch）：第 20–70 个 epoch 平均 CAM 105.56、CAMPrior 104.67（好 0.89）；同预算 RLSA 108.71，Gurobi 104.01。第 80–100 个 epoch 待 sd 集群补。
- 读法：和 MaxCut 类似，CAMPrior 起点更好、收敛更快、训练后略好。

### 4.8 更广：最大团（RB-[200-300]，越大越好）

- 训练前：CAM 16.89，CAMPrior 18.72（≈ 同预算 RLSA 18.81）。不加正则时两者训练后都退化到 12–17；RB-[800-1200] 同样退化。
- 参照（RLSA 论文表 2）：RLSA 18.97，RLNN 18.13，DiffUCO 16.22，Gurobi 19.05。
- 11-14 试了三类修正（详见 `docs/status.md` §2.11）：
  - CAM 标签 + 重定位：第 1 个 epoch 18.13，之后掉到 16.6；
  - 块动作标签：18.27 / 18.36 / 18.45，不崩但只有约 3 个点有非零标签，"稳"可能来自标签稀疏；
  - **CAM 论文附录 C.1 的翻转数正则** α(Σp_i − Δ)²（RLSA 论文式 18；RLNN 用 λ = 0.5、Δ = 2）：λ = 0.5 只把崩溃推迟到第 3 个 epoch；λ ≥ 20，或 λ = 5 配切段 / 平滑标签，能稳住 5 个 epoch，停在 18.4–18.5，仍低于训练前 18.72。
- 11-15 跑满 100 个 epoch 的 6 组（CAMPrior 4 组、CAM 2 组）训了 2 个 epoch 后按要求停掉：CAMPrior 18.2–18.5；CAM（λ = 20，Δ = 10）17.06 → 17.80，Δ = 2 时 16.80 → 15.81。checkpoint 在 `runs/cam/mcl_rb_small_reg/`。

## 5. 总结：约束越强，局部修改的收益越小

| | MaxCut | MIS | 最大团 |
|---|---|---|---|
| 约束 | 无约束 | 相邻两点不能同时选 | 选中的点必须两两相连 |
| 局部修改 | 翻任一点都可行 | 常有"空闲点"可直接加入 | 极大团处任何单点修改都变差，要先删一个再加两个 |
| CAMPrior vs CAM | 收敛更快，最优效果接近 | 收敛更快，最优效果更好 | 尚未有效：加了翻转数正则后能稳住，但还没超过训练前 |

最小支配集（非 QUBO）的表现和 MaxCut 类似。
