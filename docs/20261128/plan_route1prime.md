## 0. 目标（用户 11-28 的要求）

- 起点分布 π_A：均匀 Bernoulli(0.5)^n。
- 终点分布 π_B：单标签、多标签、多标签 + 局部扰动（按能量加权）等，逐个尝试。
- 用**两个模型**：一个学"从起点到终点"（生成方向），一个学"从终点到起点"（加噪方向）。前向不再是手工固定的加噪过程，也由模型来做。
- 按经典薛定谔桥的方式交替训练两个模型。

已有共识（11-28）：路线 1 的薛定谔桥起点–终点配对让模型学到就近对应，少步数（5–10 步）稳定提升，50 步与独立配对打平。路线 1' 想检验：换成经典的交替训练方式，能否把这一点推进。

## 1. 文献：经典薛定谔桥怎么训练

### 1.1 IPF 与 DSB（De Bortoli 等 2021，arXiv 2106.01357，`ref/lit_pdfs/2106.01357.txt`）

- **问题**（式 9）：在路径分布中找与参考过程 p 最接近（KL 最小）、且起点边缘为 p_data、终点边缘为 p_prior 的那个。
- **IPF**（式 11，第 317–321 行）：从 π^0 = p（参考加噪过程）出发，交替做两个"半桥"投影：
  - π^{2n+1} = argmin KL(π | π^{2n})，只约束噪声端 = p_prior；
  - π^{2n+2} = argmin KL(π | π^{2n+1})，只约束数据端 = p_data。
- **关键表示**（命题 2，第 329–338 行）：每个半桥的解就是"把上一个过程时间反转，再换上正确的一端"：
  - q^n = p_prior(x_N) · Π p^n_{k|k+1}：上一轮前向过程的**反向转移**，从先验出发；
  - p^{n+1} = p_data(x_0) · Π q^n_{k+1|k}：上一轮反向过程的**前向转移**，从数据出发。
  
  所以每一轮只需要"学会把对方的过程反过来走"。
- **算法 1（DSB，第 405–432 行）**：两个网络 F（前向）、B（反向）。
  - 先固定 F，从 p_data 出发用 F 模拟整条轨迹，训练 B 把它反过来；
  - 再固定 B，从 p_prior 出发用 B 模拟整条轨迹，训练 F 把它反过来；
  - 重复 L 轮。初始化 F^0 = 参考过程，所以 **B^0 就是普通扩散模型**（附录 I）。后面的轮次可以从上一轮微调。
  - 原文提醒（第 395–397 行）：两个网络如果**同时**训练，平衡点是某个桥，但不一定是薛定谔桥。必须交替。
- **收敛**（§3.4，第 440 行起）：有限离散空间上 IPF 以几何速率收敛（Franklin & Lorenz 1989）。命题 4、5 给出一般情形的单调性与收敛到薛定谔桥。
- 原文的动机之一（第 74–75 行、第 420 行）：步数少时，普通扩散的加噪到不了先验；薛定谔桥不需要加噪跑到先验，所以**需要的步数更少**。这和我们"少步数时薛定谔桥更好"的结果方向一致。

### 1.2 IMF 与 DSBM（Shi 等 2023，arXiv 2303.16852）

- IMF 交替做"互易投影"（用参考桥把配对补成路径）与"马尔可夫投影"。与 IPF 不同，IMF 每轮都保持两端的边缘不变（第 87–88、258–259 行）。
- **命题 10（第 357–361 行）**：DSBM 用参考过程的两端联合分布初始化（称 DSBM-IPF），迭代与 DSB 的 IPF 完全相同；用独立配对初始化则称 DSBM-IMF。
- DSBM 对 DSB 的批评（第 365–376 行）：
  - DSB 训练要用对方模型的**整条轨迹**，计算和存储都重；
  - 理论上每个 IPF 迭代都应在参考过程的"互易类"里，但实践中会"遗忘参考桥"（引 Fernandes 等 2021）。DSBM 用显式的互易投影来抵消。
- 二维实验（表，第 470–480 行）：DSB 的 W2 普遍差于 DSBM-IPF / IMF（例如 moons 0.190 对 0.140）。

### 1.3 离散空间（已在 `docs/20261125/math_route1.md` §12 整理）

- CSBM（Ksenofontov & Korotin 2025，arXiv 2502.01416）：离散时间、有限类别空间上的 D-IMF，两个网络严格交替（算法 1）。网络预测终点，转移取"对预测终点求期望的参考桥转移"（式 9）。
- DDSBM（Kim 等 2025，arXiv 2410.01500）：连续时间离散空间，同样前后向交替。
- 两篇都是 IMF 一类；离散空间上**按 DSB 的方式做 IPF（用整条模拟轨迹训练）**我们没找到先例。

## 2. 设定与记号

- 一张图 n 个节点，状态 x ∈ {0,1}^n。离散时间 k = 0, …, N（沿用 DIFUSCO 约定：k = 0 是终点/数据端，k = N 是起点/噪声端）。
- π_B：终点分布（标签一侧），π_A = Bernoulli(0.5)^n：起点分布。
- 参考过程 R：逐位对称翻转链，信号表 1 = a_0 > … > a_N ≥ 0（`math_route1.md` §1）。a_N = 0 时噪声端完全混合（DIFUSCO 的设定），a_N > 0 时保留一点起点信息（路线 1 的 ω）。
- 两个模型：
  - 加噪方向 F_θ：转移 q_θ(x_{k+1} | x_k)，从 π_B 走到 π_A；
  - 生成方向 B_φ：转移 p_φ(x_k | x_{k+1})，从 π_A 走到 π_B。推理只用 B。

## 3. 路线 1' 的 formulation：离散 IPF

### 3.1 两个半桥各自是一个最大似然问题 [推导]

- **生成方向的更新**：π^{2n+1} = argmin { KL(π ‖ π^{2n}) : π_N = π_A }。由 KL 的链式法则，解是 π_A(x_N) · Π_k π^{2n}(x_k | x_{k+1})。
  - 其中 π^{2n} = π_B(x_0) · Π_k q_θ(x_{k+1} | x_k) 是当前加噪模型从 π_B 出发的过程。
  - 所以 B_φ 的训练目标是：在加噪模型模拟的轨迹上，**最大化 Σ_k log p_φ(x_k | x_{k+1})**。这等价于逐步最小化 E KL(π^{2n}(· | x_{k+1}) ‖ p_φ(· | x_{k+1}))，最小点就是精确的反向转移。
- **加噪方向的更新**：π^{2n+2} = argmin { KL(π ‖ π^{2n+1}) : π_0 = π_B }。对称地，F_θ 在**生成模型从 π_A 出发模拟的轨迹**上最大化 Σ_k log q_θ(x_{k+1} | x_k)。
- 这是 DSB 命题 2、3 的离散版：连续空间里反向转移用均值回归来拟合，离散空间里直接做最大似然，不需要近似。

### 3.2 两种参数化（这是要用户决定的主要选择）

**参数化 E：预测终点，转移由参考桥给出（推荐作主方案）**

- B_φ 输出每个节点"最终在解里"的概率 P̂(x_{0,i} = 1 | x_{k+1})，转移取 D3PM 后验 Σ_y P̂(y | x_{k+1}) R(x_k | x_{k+1}, y)。这就是现有 DIFUSCO 的网络加后验采样器。
- F_θ 输出每个节点的起点值概率 P̂(x_{N,i} = 1 | x_k)，转移取朝预测起点走的参考桥 Σ_z P̂(z | x_k) R(x_{k+1} | x_k, z)。这就是 1D 的后向网络（`--sb_reverse`）。
- **为什么是精确的 [推导]**：IPF 每一步只在路径分布上乘一个"只依赖一端"的函数，所以所有迭代都有形式 π^m = R(路径) · φ_m(x_0) · ψ_m(x_N)（DSB 附录 D.2 的势函数表示）。这种分布在给定 x_{k+1} 后，未来与过去条件独立，于是反向转移恰好等于"终点后验 × 参考桥"。这也是 `math_route1.md` 命题 5.1 的同一论证。只有"网络给出逐位边缘而非联合后验"这一处近似。
- 损失：预测终点对轨迹实际终点的逐位交叉熵（与 CSBM 式 10、我们推论 3.2 的最小点相同）。

**参数化 F：两个方向都直接输出每个节点的翻转概率（"打破扩散范式"的字面做法）**

- B_φ、F_θ 都输出逐节点、逐步的翻转概率，不借助参考桥的结构，与 Shengyu 的 SBPD 加噪器同一形式。
- 参考过程只在初始化时出现（F^0 = R），之后完全靠"互相时间反转"。
- 理论极限仍是相对于 R 的薛定谔桥（每个半桥的精确解不变）。
- 风险：这正是 DSBM 说的"遗忘参考桥"（§1.2）。误差每轮累积，迭代可能漂离互易类。每一步的转移是逐节点独立的乘积，单步只丢同一步内各节点之间的相关性，每步翻转很少时这个误差小（`math_route1.md` §5 的 O(1/N) 论证）。

### 3.3 两种喂数据的方式（参数化 E 下）

- **轨迹式（DSB）**：网络的输入 x_{k+1} 直接取自对方模型模拟的整条轨迹。
- **端点式（DSBM-IPF）**：只从对方模型的模拟里取两端配对 (x_0, x_N)，中间状态从参考桥重新抽。
- 理想情况下两者相同（迭代在互易类里，给定两端时中间就是参考桥）。差别只来自网络误差。
  - 轨迹式的好处是**网络看到的输入正是它（或上一轮的它）推理时会走到的状态**。这对应 SL 对 UL 研究里最大的一个因素：训推不一致（`docs/20261116/sl_vs_ul_findings_1121.md` §1）。
  - 代价：要缓存整条轨迹，比端点式大约 N 倍存储。
- 与 1D 的关系：1D = 参数化 E + 端点式 + 独立配对初始化（DSBM-IMF），ω = 0.35。IPF 与 IMF 只差初始化：IPF 从参考过程的两端联合分布出发。a_N = 0 时参考过程的两端独立，两种初始化重合，所以**参数化 E + 端点式 + a_N = 0 就是 1D 的算法换到 a_N = 0**；a_N > 0 时初始化不同，但两者理论极限相同。路线 1' 真正新的部分是：轨迹式喂数据，以及参数化 F。

### 3.4 三种终点分布在理论上分别是什么

| 终点 π_B | 静态薛定谔桥（起点–终点配对） | 对路线 1' 的含义 |
|---|---|---|
| 单标签 s | 只能是 δ_s ⊗ π_A，配对没有内容。a_N = 0 时整条薛定谔桥就是参考过程本身，IPF 第 0 轮（普通 DIFUSCO）已经是答案 | 只作检查：多轮迭代后不应变差。这也说明 Shengyu 的 SBPD（参考过程最后一步翻转概率恰为 0.5）在理论上应学回参考过程 |
| 多标签（KaMIS 约 42 个、k128 等） | 有闭式解（Sinkhorn，路线 1） | 可以直接检查学到的配对是否收敛到闭式解；极限下与 1C / 1F 相同 |
| 多标签 + 局部扰动，按能量加权 | 解集合很大或只能拿到样本时，Sinkhorn 每图逐个算不现实 | **这是两个模型交替训练真正必要的场合**：IPF 只需要 π_B 的样本 |

扰动终点的建议定义（待确认）：π_B(s) ∝ exp(|s| / T)，s 取遍"离某个 KaMIS 解 Hamming 距离 ≤ r 的独立集"，用 Metropolis 链（加点 / 删点 / 交换）从 KaMIS 解出发采样，每图存 M 个样本。阶段 E 里"踢一下 + 局部搜索"的版本在 SL 下有害（−0.05 到 −0.09），这次要看 IPF 下结论是否改变。

## 4. 收益可能从哪里来（假设，事先写下）

- **H1 训推一致**（轨迹式）：B 在 F 的轨迹上训练，F 又是在 B 自己的轨迹上训练出来的，B 第 n+1 轮看到的输入分布向它推理时的状态靠拢（类似 DAgger）。预测：50 步和少步数都可能受益，后验采样器受益更大（11-21 的 SL 研究里后验采样器的训推差距最大）。
- **H2 少步数**：DSB 原文的动机（§1.1）。预测：5–10 步的优势比路线 1 更大。
- **H3 终点只给样本**：扰动加能量的终点不需要 Sinkhorn。
- **不预期的**：在终点是有限标签时，IPF 的极限与路线 1 的闭式薛定谔桥是同一个对象。所以如果只看"学到的目标"，50 步不应比 1F 好；有提升的话应来自 H1。

## 6. 风险

- **和照搬文献相比**：
  - DSB 在连续空间上本身就不如 DSBM（§1.2 表）。照搬 DSB 可能只得到更差、更贵的 1D。
  - 轨迹缓存 N 倍于端点缓存（4000 图 × 16 条 × 50 步），要分块存。
- **方案本身**：
  - 有限标签终点下，理论极限与闭式解相同（§4），提升只能来自 H1/H2。可能的结果就是"再一次打平"。
  - 参数化 F 的误差累积（遗忘参考桥），可能几轮后变差；P1 要先看清楚。
  - IPF 只在交替的一端精确满足边缘：轮数不够时，B 生成的终点分布不一定是 π_B。
  - **网络不看时间**：现在的 `EncodeProcessDecode` 不使用时间输入（`docs/20261116/handoff.md` 第 153 行）。参数化 F 的翻转率必须随步数变，不看时间几乎不可行；参数化 E 的理论目标也随时间变。建议路线 1' 两个网络都用带时间的 `EncodeProcessDecodeTime2`，并补一个"同样带时间的 SL"对照，否则比较不公平。

## 7. 需要用户决定

1. 主参数化：E（推荐：精确、复用现有代码和检查点）还是 F（"打破扩散范式"的字面做法，误差累积风险大）？建议 E 为主、F 为对照臂，两者都先过 P1。
2. 参考过程：a_N = 0（与 DIFUSCO 一致，单标签时薛定谔桥退化为参考过程）还是 ω = 0.35（路线 1 选定）？建议两个都做。
3. 主指标：沿用"50 步 best-of-20 MIS"，还是把少步数（5–10 步）和"生成分布是否接近 π_B"也列为主指标？
4. 网络是否统一换成带时间输入的版本（影响所有对照）。
5. 扰动终点的定义（§3.4：Hamming 半径 r、温度 T、MCMC 样本数 M）。
